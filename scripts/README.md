# 脚本

`validate_project.py` 检查必需文件、双端 manifest 共享字段、七个生命周期角色及其专业契约。对每个 Skill，它按 Markdown 章节核验角色定位、专业能力来源、项目记忆、执行流程、输出、交接门禁与边界，并确认主文件不再重复职责、核心能力或专业决策顺序。对应 `references/` 能力手册必须包含角色职责、核心能力、专业决策顺序、交付证据、常见误判及角色专属能力词，避免无关位置的同名词误过门禁。

校验器还会确认七个 Skill 均为唯一单词，且 Skill、同名模板与同名项目记忆一一对应；确认 Codex `default_prompt` 同时调用对应 Skill 并采用该角色身份；确认七职既可按需直调，也只在门禁通过且写入不冲突时并行；确认当前项目事实基线、带来源的外部参考、读取与写入授权分离及动态收口契约；并检查七份模板是否具备 AI 恢复所需的修订、摘要、稳定依据、动作、验证、交接、失效条件和角色专属章节。旧式“只读当前项目材料”来源白名单会被视为退化。

在插件根目录运行：

```powershell
python scripts/validate_project.py
```
