# discovery

- 固定责任角色：`discovery`（产品经理）
- 项目根：当前 `product-studio` 仓库
- 记忆路径：`docs/product-studio/discovery.md`

## 恢复摘要

- 当前产品问题：项目记忆须让后续 AI 直接理解项目已经成立的具体行为、关键值、边界、因果关系与证据；它既不能写成过程流水账，也不能以整文件覆盖删去仍有效事实。
- 当前范围结论：保留既有八字段能力手册；每份模板只以完整角色事实家族索引和一张可复制的十三字段通用骨架首次创建 schema 2 详细事实册，不再为每个家族预铺空卡，角色专业细节仍唯一保存在对应 `skills/*/references`。既有 schema 1/2 不读取模板或迁移；任务形成可交付终态且完成适用验证后，跨角色顺序由 `delivery` Skill 路由，仅由事实变化角色依据同名 Skill 的项目记忆契约与自身事实卡按稳定 ID 增量合并已成立事实，无增量不修改文件或时间戳。
- 首个可执行动作：无；`delivery` 跨角色总路由、七份同名 Skill 的项目记忆契约、模板、校验器、七职记忆和 fresh backend/delivery 行为验证均已收口。
- 阻塞：无；实际安装与发布不在授权范围，但不构成源码交付阻塞。

## 原始意图

- 用户要求七个技能的名称收紧为一个符合该技能的单词。
- 用户要求每个技能的记忆与技能名称一致，以提升阅读性。
- 用户要求记忆模板更有利于 AI 在氛围编程中恢复、判断和继续执行。
- 用户指出“只读取”“不得从”限定过死，会造成 AI 上下文缺失，并以参考链接页面进行仿照为具体反例。
- 用户要求检查其他位置的同类问题并一并修正。
- 用户要求删除七份 `SKILL.md` 中的职责、核心能力、专业决策顺序，并根据原核心能力详细扩充各角色 reference，由 Skill 引用该职责能力。
- 用户进一步确认 reference 应删除宽泛角色职责，以既有核心能力为骨架，改写为模型可直接执行的明确能力卡并减少重复。
- 用户随后指出上一轮改写后的提示词更宽泛、没有改前详细，要求恢复可直接执行的具体判断、证据要求、失败模式与反例，而不是继续以压缩为目标。
- 用户要求氛围编程执行过程中不要持续更新项目记忆，只在任务完成后记录最后一次事实结果。
- 用户随后纠正：完成后也不得整文件覆盖；各受影响角色须对自己文件做一次事实级增量合并，保留仍有效事实与未受影响章节，无事实增量不修改文件或时间戳。
- 用户进一步确认：模板格式应保存已成立的项目详细事实，使后续 AI 能清晰理解项目，而非恢复摘要、动作队列或任务过程。

## 用户问题与目标结果

- 主要用户：在 Codex 或 Claude Code 中按需调用产品研发角色的氛围编程用户与后续 AI 会话。
- 待完成任务：既能从当前项目记忆恢复事实、使用任务相关外部材料，又能在一次氛围编程结束时只合并经验证的事实增量。
- 可感知结果：AI 不会因项目隔离拒绝显式参考，不会把外部语义冒充当前事实，也不会在过程阶段写记忆或在终态重建整个文件。
- 成功信号：每项外部输入有精确来源、用途、适用性和采纳状态；读取范围与写入授权分离；增量场景保留不变事实、更新变化事实并新增事实，中断场景记忆零改动。

## 范围与非目标

### 本轮包含

- 七个 Skill 目录、frontmatter、显式调用与 UI 默认提示词迁移。
- 七份同名模板和当前项目记忆迁移。
- 七份首次建档模板各提供完整角色事实家族索引与一张十三字段通用骨架；角色专业细节仍由同角色 reference 提供，不再在模板预铺详细空卡或保存恢复摘要、动作队列等过程结构。
- 校验器、README、七份同名 Skill 的项目记忆契约、CHANGELOG 与当前记忆同步。
- 七职 Skill 与模板的来源边界改为当前项目事实、外部参考、明确采纳三层语义。
- 七职 Skill/reference 专业分层，以及七份 reference 从职责叙述改为保留全部既有核心能力 H3 的四段式能力手册；每卡以八字段恢复改前专业细节，并以结构、语义和行为门禁防止再次宽泛化。
- 跨角色终态总路由归 `delivery` Skill，各角色事实规则归同名 Skill；七份 Skill 与模板采用终态后按角色事实级增量合并，校验器阻止过程写入、全量覆盖、无事实增量改时间戳、过程尝试追加及失败依赖增量形成悬空引用。

### 本轮不包含

- 不保留七个旧名的兼容 Skill 壳。
- 不安装插件、不刷新本地缓存、不执行发布或外部变更。
- 不把模板变成长期流水日志；完整历史由 Git 保存。

### 不得破坏

- 七职角色身份、专业能力、按需直调、安全并行、单一写入所有权、事实归属、读取与写入授权分离及秘密保护边界。
