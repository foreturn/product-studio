# release-engineering 当前产品事实 · 授权、隔离与审计

## 授权覆盖与会话内复用

- **当前事实**：发布工程对提交、推送、标记、上传、部署、迁移、切流与恢复逐项核对授权覆盖的对象、环境、范围与条件；同一会话中仍适用的已有授权继续有效，一次授权可涵盖一组明确动作。代码完成、检查通过、具备凭据或其他范围的批准不能扩大写入权限，逐项核对也不要求反复确认已授权动作。
- **权威依据**：`skills/release-engineering/references/principles/authorization-audit.md`；`skills/release-engineering/references/memory/authorization-audit.md`。
- **影响边界**：仅在拟执行动作超出已有授权范围或条件失效时补足授权；持久项目记忆保存授权政策与失效条件，会话中的具体批准不作为未来任务的授权凭据。
- **复核入口**：以范围内重复核对、授权覆盖多项动作、变更目标环境和已失效授权四类情形检查继续执行与补足授权的边界；授权政策或会话范围规则变化时重审。
