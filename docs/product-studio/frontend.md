# frontend 当前项目事实

## 前端实现职责

- **当前事实**：`frontend` 依据已确认的产品任务、接口契约和适用架构决定，通过任务可用性与信息架构、交互与状态工程、数据与接口集成、组件与视觉体系、布局与响应式、可访问性、前端安全与隐私、性能与运行健壮性、测试与真实渲染验收九项能力落实界面与浏览器行为；不在实现层猜造产品、接口或系统语义。
- **权威依据**：`skills/frontend/SKILL.md#输入门禁`；`skills/frontend/SKILL.md#实施流程`；`skills/frontend/references/principles.md#核心能力`
- **影响边界**：页面、路由、组件、设计令牌、请求适配、前端状态、目标浏览器与视口，以及 `verification` 接收的真实界面证据。
- **复核入口**：以局部样式修复、接口状态页面和跨边界语义未定三类全新请求试用 `frontend`，核对前两者只加载命中的能力并取得相称浏览器证据，后者退回对应专业 Skill，且均不以构建或截图替代真实交互。
