# 数据库工程项目记忆

## 核心记忆

### 物理模型、标识与强制不变量

- 记住数据库中每类持久事实、当前状态、历史记录与事件记录的实际结构、类型精度、可选性、关系基数和生命周期语义，以及稳定主键、自然唯一性、展示编号与访问凭据之间的区别。
- 记住唯一性、引用完整性、状态约束、删除规则和跨写入口共享不变量中哪些由目标数据库真实强制，哪些仍由应用或人工流程承担，以及依赖这些保证的读写消费者。
- 记住规范化后的唯一写入位置、可重建派生值和有意冗余的同步责任，逻辑删除、历史保留与最终清除如何共同影响查询可见性、唯一性、审计和引用关系。

### 查询、索引、分页与执行计划

- 记住决定物理模型和索引的关键过滤、关联、排序、分页、聚合和批量访问路径，其调用频率、参数分布、结果规模、稳定排序裁决与恢复需求。
- 记住每个重要索引服务的访问形态、列序、覆盖与过滤范围，所承担的写放大、存储和维护成本，以及删除、替换或改变索引前必须存在的替代路径。
- 记住代表性数据规模、倾斜、统计信息和实际执行计划下的基线、热点与退化方式，哪些查询不在当前保障范围，哪些结论不能从语句外观、空库或单次样本外推。

### 事务、隔离、锁与并发裁决

- 记住关键操作必须共同成立的业务不变量、实际事务边界、隔离级别、锁定对象和稳定访问顺序，以及允许与禁止的脏读、不可重复读、幻读、写偏斜和丢失更新现象。
- 记住条件写、唯一约束、版本、锁或租约如何确认变更真正生效，热点、阻塞与死锁如何观测，冲突和陈旧执行者对应用返回何种可重试或不可重试结果。
- 记住连接中断、超时和未知提交后的确定处置，重试预算与业务幂等前提，以及跨数据库、消息和其他外部副作用明确不受本地事务保护的边界。

### 结构演进、迁移与数据交换

- 记住 Schema 和数据格式演进期间必须共存的新旧应用、读写路径与消费者组合，新增、切换、收缩和破坏性删除的顺序、当前权威、兼容期限与退出条件。
- 记住回填、转换、导入和同步的稳定身份、批次边界、顺序、幂等、断点续跑、暂停和重入语义，以及锁、日志、复制延迟、存储和在线负载的资源上限。
- 记住迁移和交换完成必须核对的数量、引用、空值、唯一性、领域不变量与代表内容，全量快照同增量变化的切换边界，以及传输完成、脚本退出和结构版本不能单独证明的终态。

### 分区、归档、保留与删除传播

- 记住分区键同主要访问、写入分布和生命周期操作的关系，跨分区唯一性、引用与全局查询由何处保证，以及查询能否实际裁剪分区的验证入口。
- 记住每类关键数据从何种业务事件起算保留期，何时转入归档、怎样保持检索和访问控制，何时允许清除，以及主库、副本、缓存、搜索、分析和备份中的传播范围。
- 记住归档或批量删除对引用、审计、恢复链、锁、日志和资源峰值的限制，目标副本必须满足的完整性与可恢复条件，以及法律保留或在用引用阻止清理的边界。

### 连接、会话、容量与维护治理

- 记住所有应用实例、后台任务和管理入口共享的连接总预算、池化模式、排队与背压规则，以及事务、游标、身份、租户和会话变量在连接归还前的清理保证。
- 记住连接、语句、锁和事务时限同端到端服务预算的关系，池满、数据库不可用和并发重连时的保护行为，以及不依赖业务连接池的诊断与恢复通道。
- 记住容量模型覆盖的数据、索引、日志、临时空间、备份、迁移和重建峰值，统计、清理、压缩与回收的长期维护负担、增长趋势、告警提前量和必须保留的故障余量。

### 复制、读取一致性与高可用

- 记住复制拓扑、提交确认方式与同步程度在延迟、吞吐、可用性和可接受数据损失之间的当前取舍，以及每类读取允许的陈旧度、读己之写和单调读取保证。
- 记住复制延迟、积压、重放位置和分叉由哪些信号判断，何时停止不安全只读流量或高负载维护，以及故障节点重新接入前必须满足的一致性条件。
- 记住主节点仲裁、隔离和名称切换如何保证单一可写来源，节点、链路与网络分区演练实际证明的恢复时间和数据损失范围，以及哪些部署形态不受高可用承诺覆盖。

### 备份、时间点恢复与业务复原

- 记住恢复点与恢复时间目标对应的数据范围、故障模型、备份类型、保存周期和独立故障域，基线、增量记录、元数据、配置与密钥如何形成连续可验证的恢复链。
- 记住备份写出、完整性校验和恢复演练各自证明的范围，恢复结果必须重新验证的结构、数据不变量、关键业务读取、应用兼容与外部依赖。
- 记住主环境不可用时仍可取得的恢复身份、工具和入口，恢复期间隔离旧写源、防止双写与按依赖顺序恢复的机制，以及备份明确未覆盖的对象和外部副本。

### 数据身份、权限、审计与敏感边界

- 记住运行、迁移、分析、备份和管理身份的权限边界、默认授权和临时提升机制，哪些结构或全局能力绝不属于普通应用身份，以及连接复用时可信策略上下文如何保持隔离。
- 记住敏感字段在传输、存储、查询、索引、日志、备份和非生产数据集中的保护、脱敏或令牌化方式，密钥与数据访问的隔离关系，以及哪些字段组合仍可能重新识别主体。
- 记住数据库审计记录的可信主体、动作、对象、结果、时间和关联标识，审计与普通诊断日志的边界，以及秘密、完整敏感载荷和生产样本不得进入的记录或测试表面。
