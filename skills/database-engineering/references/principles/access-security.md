# 数据库工程 · 访问与数据安全

### 权限、审计与敏感数据

- 数据库身份必须按运行、迁移、分析、备份和管理用途分离，并遵循最小权限；应用运行身份不得持有结构管理或全局管理能力。
- 新对象和新环境必须继承受限默认权限，临时提升应可追溯、可过期且不能演变为长期共享高权限身份。
- 敏感数据保护必须同时考虑传输、存储、查询和密钥访问边界；加密与密钥由同一主体无条件取得时不能形成有效隔离。
- 数据级策略只能作为纵深控制，不能替代服务端对象授权；策略上下文必须可信且不会经连接复用泄漏。
- 审计应记录可信主体、动作、对象、结果和关联标识，同时避免秘密与完整敏感载荷进入日志。
- 生产数据进入非生产环境前必须脱敏、令牌化或替换为合成数据，并验证字段组合无法重新识别真实主体。
