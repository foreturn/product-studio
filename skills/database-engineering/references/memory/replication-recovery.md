# 数据库工程项目记忆 · 复制、恢复与高可用

- 记住复制拓扑、提交确认方式与同步程度在延迟、吞吐、可用性和可接受数据损失之间的当前取舍，以及每类读取允许的陈旧度、读己之写和单调读取保证。
- 记住复制延迟、积压、重放位置和分叉由哪些信号判断，何时停止不安全只读流量或高负载维护，以及故障节点重新接入前必须满足的一致性条件。
- 记住主节点仲裁、隔离和名称切换如何保证单一可写来源，节点、链路与网络分区演练实际证明的恢复时间和数据损失范围，以及哪些部署形态不受高可用承诺覆盖。
- 记住恢复点与恢复时间目标对应的数据范围、故障模型、备份类型、保存周期和独立故障域，基线、增量记录、元数据、配置与密钥如何形成连续可验证的恢复链。
- 记住备份写出、完整性校验和恢复演练各自证明的范围，恢复结果必须重新验证的结构、数据不变量、关键业务读取、应用兼容与外部依赖。
- 记住主环境不可用时仍可取得的恢复身份、工具和入口，恢复期间隔离旧写源、防止双写与按依赖顺序恢复的机制，以及备份明确未覆盖的对象和外部副本。
