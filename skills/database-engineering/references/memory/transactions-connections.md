# 数据库工程项目记忆 · 事务、并发与连接

- 记住关键操作必须共同成立的业务不变量、实际事务边界、隔离级别、锁定对象和稳定访问顺序，以及允许与禁止的脏读、不可重复读、幻读、写偏斜和丢失更新现象。
- 记住条件写、唯一约束、版本、锁或租约如何确认变更真正生效，热点、阻塞与死锁如何观测，冲突和陈旧执行者对应用返回何种可重试或不可重试结果。
- 记住连接中断、超时和未知提交后的确定处置，重试预算与业务幂等前提，以及跨数据库、消息和其他外部副作用明确不受本地事务保护的边界。
- 记住所有应用实例、后台任务和管理入口共享的连接总预算、池化模式、排队与背压规则，以及事务、游标、身份、租户和会话变量在连接归还前的清理保证。
- 记住连接、语句、锁和事务时限同端到端服务预算的关系，池满、数据库不可用和并发重连时的保护行为，以及不依赖业务连接池的诊断与恢复通道。
