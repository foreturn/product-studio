# 数据库工程项目记忆 · 迁移、生命周期与数据交换

- 记住 Schema 和数据格式演进期间必须共存的新旧应用、读写路径与消费者组合，新增、切换、收缩和破坏性删除的顺序、当前权威、兼容期限与退出条件。
- 记住回填、转换、导入和同步的稳定身份、批次边界、顺序、幂等、断点续跑、暂停和重入语义，以及锁、日志、复制延迟、存储和在线负载的资源上限。
- 记住迁移和交换完成必须核对的数量、引用、空值、唯一性、领域不变量与代表内容，全量快照同增量变化的切换边界，以及传输完成、脚本退出和结构版本不能单独证明的终态。
- 记住分区键同主要访问、写入分布和生命周期操作的关系，跨分区唯一性、引用与全局查询由何处保证，以及查询能否实际裁剪分区的验证入口。
- 记住每类关键数据从何种业务事件起算保留期，何时转入归档、怎样保持检索和访问控制，何时允许清除，以及主库、副本、缓存、搜索、分析和备份中的传播范围。
- 记住归档或批量删除对引用、审计、恢复链、锁、日志和资源峰值的限制，目标副本必须满足的完整性与可恢复条件，以及法律保留或在用引用阻止清理的边界。
