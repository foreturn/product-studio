# Web 工程项目记忆

## 核心记忆

### 应用结构、入口与渲染边界

- 记住项目实际存在的浏览器入口、应用壳、共享布局、页面与功能模块各由谁拥有，关键用户操作从入口经路由、共享状态和适用数据契约到达何种业务结果与恢复路径，哪些入口共同复用同一业务模型与能力，以及相应公共接口、依赖方向和禁止跨越的内部边界。
- 记住每个入口采用服务端渲染、构建期生成、流式呈现还是纯客户端运行，服务端、构建期与浏览器端分别拥有何种事实，以及首次呈现、序列化载荷、客户端水合和后续刷新必须保持一致的确定性输入。
- 记住应用启动时部署基路径、静态资源前缀、运行时公开配置、身份上下文、功能开关与浏览器能力的提供者和初始化顺序，以及无脚本、弱网、配置缺失、资源失败或初始化中断时仍须保留的入口、内容与恢复路径。

### URL、导航与任务恢复

- 记住每项核心任务的稳定 URL、路径参数、查询参数与片段分别表达何种资源或任务状态，由哪一层校验、规范化和生成，以及哪些状态可分享、刷新、书签恢复，哪些敏感或短暂状态不得进入地址。
- 记住路由所有者、应用壳层级、主导航、当前位置、页面标题和返回关系，以及地址栏直达、站内导航、外部深链、未知资源、无权访问、认证失效、永久删除与系统故障各自应返回的页面、状态或重定向。
- 记住列表进入详情再返回、浏览器前进后退、刷新和部署回退时必须恢复的筛选、排序、分页、展开、选中项与滚动位置，以及未提交编辑或进行中操作在离开、重入和会话恢复时的保留、舍弃与继续规则。

### 状态权威、身份与浏览器持久化

- 记住远端业务事实、查询缓存、表单草稿、局部交互和跨页面任务状态分别由哪个 store、URL、组件或服务端资源拥有，其唯一权威、派生关系、同步方向、存活期及在成功、取消、离开和错误后的重置条件。
- 记住账户、租户、角色和匿名会话的客户端隔离键与传播方式，以及登录、退出、身份切换、权限变化、令牌失效和跨标签页同步时哪些缓存、草稿、待处理写入、订阅与连接必须清理、失效或重建。
- 记住每类浏览器持久化数据究竟是设置、缓存、草稿还是离线副本，使用何种存储与结构版本，如何迁移、校验和损坏恢复，其容量、驱逐、多标签并发与身份作用域边界，以及恢复联网或会话重建后同服务端权威收敛的规则。

### 远端数据、缓存、并发与实时

- 记住共享请求、传输模型转换和查询缓存的所有者，缓存键完整覆盖的参数、账户、租户与权限作用域，写入影响的失效或局部更新范围，以及初次加载、保留旧内容的刷新、分页追加和局部更新分别如何呈现。
- 记住读取取消与去重、陈旧响应丢弃、不可并发写入排序、批量资源上限、瞬态故障重试、幂等保证、乐观更新回滚和冲突裁决的项目约定，尤其是副作用不可逆或结果未知时禁止自动重放的边界。
- 记住实时连接和订阅由谁创建、共享与释放，消息稳定身份、重复、乱序、缺口和快照版本如何处理，断线重连从何处补齐并同权威状态收敛，以及通道可用、消息已达与数据完整三者不可混同的边界。

### 表单、数据密集工作流与错误恢复

- 记住关键表单的字段含义、默认值、依赖关系与草稿所有者，客户端可裁定的格式规则和必须由服务端裁定的资格、唯一性、权限与冲突，以及重复提交防护、幂等依据和真实业务完成标志。
- 记住表格、列表和批量工作流的列与空值语义、筛选排序和分页权威、虚拟呈现边界、选中范围与跨页行为、批量影响上限，以及尚无数据、筛选无结果、无权限、离线副本和部分失败各自的稳定含义。
- 记住初次加载、保留旧内容的刷新、部分成功、业务拒绝、认证失效、冲突、限流、离线、超时、程序异常和结果未知分别如何呈现与恢复，哪些输入和进度必须保留，哪些动作可取消、重试或回滚，哪些副作用不得重复触发。

### 组件体系、样式与交互语义

- 记住基础原语、通用交互、业务组件和页面组合的分层与真实消费者，共享组件稳定的属性、事件、插槽、受控状态和允许组合，以及组件实例和列表项依赖的数据身份、请求、监听、订阅与卸载清理契约。
- 记住设计令牌、主题语义、CSS 来源、级联顺序和作用域的权威关系，第三方样式的限定覆盖点，以及排版、间距、内容宽度、控件高度、图标、圆角、颜色和反馈状态采用的统一尺度与角色。
- 记住已确认产品内容语义的权威来源及用户可见文字从用户情境、业务对象、任务、结果和下一步呈现的边界，主次动作的位置、名称、图标、顺序和可见性，同类控件在悬停、焦点、按下、禁用、错误与加载时的交互语义，以及异步反馈、动态内容、浮层、粘性区域和滚动主体必须维持的尺寸稳定、关闭方式与焦点恢复关系。

### 响应式、无障碍、本地化与时间

- 记住核心任务从窄屏到宽屏、触控到键鼠、横竖屏切换、页面缩放、字体放大和虚拟键盘出现时必须保留的信息、操作与阅读顺序，以及哪些区域允许重排、折叠、滚动、固定或切换呈现形式。
- 记住公共交互的语义名称、角色、值与状态，键盘顺序、焦点进入与返回、错误关联、动态播报和触控目标契约，以及高对比、减少动画、不同指针能力和辅助技术下不得丢失的任务能力。
- 记住语言、消息与格式化资源的权威和版本，缺失翻译、长文本、复数、双向文本与语义镜像规则，以及业务时间使用的服务端时钟、时区、日界线、绝对时刻、当地日期和相对时长含义与转换边界。

### 浏览器信任、兼容与交付边界

- 记住富文本、文件名与文件内容、外部 URL、危险协议、跨窗口消息、iframe 和第三方脚本分别在哪个解释上下文进入浏览器，其允许来源、协议、消息发送方、净化策略、嵌入权限和最小数据访问范围。
- 记住身份凭据、敏感业务副本和用户内容在内存、浏览器存储、请求、实时连接、地址与日志中的保护、脱敏、持久化和清理边界，并明确客户端校验、路由判断、按钮禁用和界面隐藏均不构成授权权威。
- 记住产品承诺的浏览器与设备矩阵、各核心任务依赖的运行能力、特性检测和基础退化路径，以及干净环境可重复构建、浏览器公开配置、依赖锁定与退出、拆包预算和调试映射受控保存的交付边界。

### 性能、资源、验证、观测与公开页面

- 记住性能目标所对应的代表设备、网络、数据规模与生产构建条件，首屏内容、交互响应、视觉稳定和核心任务的基线、预算、测量入口与已知长尾，并区分用户结果、资源体积和实验室分数的证据边界。
- 记住监听、观察、计时、连接、后台工作、媒体、缓存和临时资源的所有者、消费者、容量、身份作用域与停止条件，哪些布局、焦点、历史、存储、多上下文和资源生命周期风险必须由真实浏览器验证，以及错误、性能与网络信号如何按版本、页面和操作关联并在采集前脱敏。
- 记住哪些页面公开、无需认证且具有独立索引价值，其规范 URL、语言变体、分页筛选策略、重定向与资源生命周期状态，抓取时主体、标题、结构化数据和分享元数据的权威来源，以及私有、重复或用户特有内容不得出现在源码、预览或索引中的边界。
