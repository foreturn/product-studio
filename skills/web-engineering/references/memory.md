# Web 工程当前产品事实规则

## 所有权与稳定位置

`web-engineering` 是浏览器端实现事实的唯一语义 Owner。稳定位置为 `docs/product-studio/<product-id>/web-engineering.md`；`product-id` 必须在同一 Git 仓库内唯一、稳定并可安全作为单级目录名。事实册只保存当前终态仍成立、会改变后续 Web 工程决策且难以从局部代码重新得出的语义事实。产品旅程、内容、交互意图、视觉层级与无障碍目标归 `product-management`；本册只引用该产品主题并记录浏览器实现不变量、平台限制与验证保证，不复制产品正文。

## 事实类型索引

1. 路由任务语义
2. 共享组件、设计系统与无障碍
3. 状态权威与持久化
4. 网络、错误与实时交互
5. 布局、响应式与本地化
6. 浏览器安全、性能与兼容

## 通用入册门禁

- 候选事实必须在当前终态已经成立，并由代码、配置、调用链或权威契约直接支撑；计划、阶段、进度、历史任务、实施过程和推断不得入册。
- 候选事实必须稳定、非显然、决策相关，会改变后续实现或验证取舍，且跨入口或跨文件重查成本较高；可由单个局部实现直接看出的细节不入册。
- 必须唯一确认 Git 根、当前产品、`product-id`、事实的唯一 Owner 和主题合并键；归属不明时不得读取、创建或修改候选事实册，同一事实不得由多个 Owner 复制持有。
- 当前事实只写业务语义、成立条件、对消费者的保证和明确限制，不复制组件树、完整路由、API 或存储定义、平台符号、文件清单及当前设备、版本或运行快照。
- 每项事实必须有可定位权威依据和风险相称的可重复复核入口，并通过秘密、个人数据与生产数据安全检查；证据不足时不得落册，终态处置只遵循公共终态协议。
- 长期兼容事实只写当前支持不变量与使其退出事实册的触发条件，不记录迁移阶段、完成比例、时间表或临时双轨进度。

## 主题表达规则

每个主题以稳定业务语义命名，不含路径、日期、任务号或动作前缀，并只容纳共同检索、共同变化的事实。根据事实类型、语义复杂度与检索需要，可使用段落、列表、表格或其组合，不强制 Markdown 标题层级、固定分栏、字段顺序或标签名称。

表达中仍须能够明确识别当前成立的事实及条件、权威依据、影响范围和复核方式：当前事实说明语义、保证与限制；权威依据收敛为一至三个可定位的仓库相对入口；影响范围说明消费者、环境与不得破坏关系；复核方式给出可重复命令或操作、关键断言、适用环境及证据盲区。各要素可自然分布，但不得缺失或依赖读者猜测。

## 动作语义

- `ADD`：稳定事实首次成立且通过全部门禁；同次创建产品目录和事实册。
- `UPDATE`：同一主题的当前语义、依据、影响或复核入口发生实质变化；原位合并，不追加历史段落。
- `DELETE`：事实已不再成立或不再由本 Owner 持有；移除主题，事实册无主题时删除本 Owner 文件。
- `NO_CHANGE`：实现可能变化，但当前事实、权威依据、影响范围与复核方式均无实质变化；不得因表达载体或排版偏好触碰事实文件。

## 事实类型

### 路由任务语义

- **入册条件**：浏览器入口族已稳定承载真实用户任务，且其进入、刷新、返回、失败或完成语义会约束多个后续改动。
- **主题合并键**：以“用户任务 + 入口族 + 完成或返回边界”合并；共同演进的入口同题，不按单个地址或页面拆分。
- **当前事实写法**：引用产品任务主题，只写其在 URL、浏览器历史与部署基路径上的入口兑现、导航保证、失败或完成映射及平台限制，不重新定义产品旅程。
- **权威依据**：引用路由配置、入口协调实现、部署回退配置和集成测试中一至三个最强定位点；菜单文案不能单独证明入口成立。
- **影响边界**：写明受约束的用户任务、身份、浏览器历史、部署基路径、服务端权限结果与非 Web 入口边界。
- **复核入口**：验证代表身份下的直达、站内进入、刷新、前进后退、非法输入、无权状态及完成去向，并注明真实部署或身份覆盖缺口。
- **变更规则**：任务入口语义、前提、保证、限制、消费者、依据或复核边界实质变化时 `UPDATE`；实现替换而四项语义等价时 `NO_CHANGE`。
- **排除项**：不记录完整路由表、菜单或页面清单、地址样本、路由符号、临时入口、迁移过程、当前访问快照或产品旅程正文。

### 共享组件、设计系统与无障碍

- **入册条件**：共享原语或设计系统已被多个真实场景依赖，并形成跨消费者稳定的交互、视觉语义或无障碍保证。
- **主题合并键**：以“共享任务原语 + 公共行为族 + 消费边界”合并；共同变化的组件、令牌和辅助行为同题。
- **当前事实写法**：引用产品体验主题，只写共享原语在浏览器中的状态实现、输入与焦点行为、视觉令牌关系、辅助技术结果、组合条件及平台限制，不复述产品内容或体验意图。
- **权威依据**：引用公共实现、设计令牌、消费场景和组件或无障碍测试中一至三个最强定位点；设计稿与截图只能补充。
- **影响边界**：写明消费任务、主题、输入方式、辅助技术、内容变化及不得破坏的公共关系，不扩大到页面私有实现。
- **复核入口**：在真实消费场景验证关键状态、键盘、焦点、辅助名称、缩放、主题与高对比结果，并说明浏览器和辅助技术覆盖。
- **变更规则**：公共语义、交互、视觉保证、无障碍结果、适用范围、依据或复核边界变化时 `UPDATE`；内部重构等价时 `NO_CHANGE`。
- **排除项**：不记录组件树、组件或图标全表、属性和事件清单、令牌值、ARIA 属性表、截图批次、扫描快照或审美偏好。

### 状态权威与持久化

- **入册条件**：业务状态的唯一权威、派生关系、恢复或浏览器持久化边界已经稳定，且错误归属会造成跨页面、跨会话或跨身份错误。
- **主题合并键**：以“业务状态语义 + 权威角色 + 生命周期边界”合并；共同初始化、失效、恢复和清理的状态同题。
- **当前事实写法**：只写状态所代表的语义、权威与副本关系、成立和失效条件、恢复保证、隔离与清理限制。
- **权威依据**：引用状态所有者、持久化适配层、生命周期实现和恢复测试中一至三个最强定位点；瞬时值或存储快照不能证明权威关系。
- **影响边界**：写明受影响任务、身份或租户、页面、会话、标签页、离线场景、服务端权威与浏览器资源限制。
- **复核入口**：验证初始化、刷新、并发响应、失效、恢复、升级中断、跨标签协调、身份切换和清理结果，并区分模拟与真实浏览器证据。
- **变更规则**：权威角色、派生关系、生命周期、恢复保证、隔离限制、消费者、依据或复核边界变化时 `UPDATE`；内部容器或存储实现替换且语义等价时 `NO_CHANGE`。
- **排除项**：不记录状态树、字段、动作、查询键、存储结构或迁移脚本全文，不保存用户数据、配额、缓存值、浏览器版本或运行快照。

### 网络、错误与实时交互

- **入册条件**：一组客户端通信已形成被多个真实消费者依赖的结果、错误、并发、重连或实时消息语义，且会改变用户可见状态。
- **主题合并键**：以“业务交互族 + 客户端适配边界 + 用户结果”合并；共享结果和故障语义的请求、流或消息同题。
- **当前事实写法**：只写交互前提、成功和失败语义、陈旧或重复结果处理、实时连接保证、恢复条件及明确不保证事项。
- **权威依据**：引用客户端适配、错误归一、实时连接实现和契约或交互测试中一至三个最强定位点；服务端文档只能说明依赖。
- **影响边界**：写明用户任务、身份、并发消费者、连接状态、缓存关系、服务端契约与用户可见反馈边界。
- **复核入口**：验证成功、业务拒绝、会话失效、离线、超时、取消、乱序、重复、断线重连与不可恢复结果，并标明真实服务证据缺口。
- **变更规则**：结果、错误、并发、实时恢复语义、适用范围、依据或复核边界变化时 `UPDATE`；传输库替换而四项语义等价时 `NO_CHANGE`。
- **排除项**：不复制端点、DTO、错误码、消息协议或请求响应清单，不保存令牌、抓包、连接日志、当前在线状态、临时 Mock 或单次失败。

### 布局、响应式与本地化

- **入册条件**：关键任务已形成跨视口、输入方式、语言、方向或时区稳定的能力保留与呈现语义，且多个界面共同依赖。
- **主题合并键**：以“用户任务或布局区域 + 呈现行为族 + 支持场景”合并；共同重排、格式化和方向适配的行为同题。
- **当前事实写法**：只写支持条件、信息与操作保留保证、重排和滚动语义、本地化权威、方向行为及明确限制。
- **权威依据**：引用共享布局、方向或格式化实现、资源装载和响应或本地化测试中一至三个最强定位点；截图只能补充。
- **影响边界**：写明任务、内容规模、视口或容器、输入方式、缩放、语言、时区、双向文本、服务端渲染及浏览器边界。
- **复核入口**：在代表场景验证窄宽布局、长内容、缩放、键盘或触控、语言切换、缺失资源、时区、RTL 与混排结果，并注明覆盖范围。
- **变更规则**：能力保留、呈现语义、本地化权威、方向保证、支持范围、依据或复核边界变化时 `UPDATE`；断点或资源组织调整但语义等价时 `NO_CHANGE`。
- **排除项**：不记录媒体查询、断点、尺寸、样式属性、语言或消息键清单，不保存 locale、时区、设备、浏览器或截图快照。

### 浏览器安全、性能与兼容

- **入册条件**：关键任务已形成跨入口复用的浏览器安全边界、资源保护或能力回退不变量，并会约束后续实现取舍。
- **主题合并键**：以“受保护任务或资源 + 控制或回退语义 + 支持环境”合并；共同变化的安全、性能与兼容保证同题。
- **当前事实写法**：只写控制成立条件、可信边界、允许和拒绝语义、资源上限或退化保证、能力缺失时结果、当前支持不变量、限制与退出触发。
- **权威依据**：引用安全适配、构建或加载边界、能力检测及安全、性能或兼容测试中一至三个最强定位点；政策与单次测量只能补充。
- **影响边界**：写明任务、身份与来源、敏感数据、资源规模、网络和设备档位、第三方内容及支持环境。
- **复核入口**：验证不可信输入、身份切换、资源受限、慢网、脚本失败和能力缺失下的正确结果，并记录实验室与真实环境证据边界。
- **变更规则**：控制语义、资源保证、回退、支持不变量、退出触发、依据或复核边界变化时 `UPDATE`；工具或实现位置变化但语义等价时 `NO_CHANGE`。
- **排除项**：不记录漏洞载荷、密钥、令牌、依赖或浏览器版本清单、性能分数、设备信息、制品时间戳、当前支持快照或兼容迁移进度。

## 全册安全与删除规则

- 禁止写入密钥、凭据、完整令牌、个人数据、生产数据、原始请求响应、浏览记录、设备标识、任务摘要、过程记录、运行快照或原始差异。
- 事实依据失效、语义被替代、退出触发成立或所有权消失时必须 `UPDATE` 或 `DELETE`；历史由 Git 承担，不保留“曾经如此”的叙事。
- 只修改语义要素或证据确有实质变化的主题；仅有表达载体、排序或排版偏好变化时判定 `NO_CHANGE`，事实册必须保持字节不变。
- 删除主题前确认没有仍成立的合并语义；只可删除本 Owner 已无主题的事实册，禁止越界删除其他内容。
