# Web 工程项目记忆 · 表单、交互反馈与可达性

- 记住关键表单的字段含义、默认值、依赖关系与草稿所有者，客户端可裁定的格式规则和必须由服务端裁定的资格、唯一性、权限与冲突，以及重复提交防护、幂等依据和真实业务完成标志。
- 记住表格、列表和批量工作流的列与空值语义、筛选排序和分页权威、虚拟呈现边界、选中范围与跨页行为、批量影响上限，以及尚无数据、筛选无结果、无权限、离线副本和部分失败各自的稳定含义。
- 记住初次加载、保留旧内容的刷新、部分成功、业务拒绝、认证失效、冲突、限流、离线、超时、程序异常和结果未知分别如何呈现与恢复，哪些输入和进度必须保留，哪些动作可取消、重试或回滚，哪些副作用不得重复触发。
- 记住核心任务从窄屏到宽屏、触控到键鼠、横竖屏切换、页面缩放、字体放大和虚拟键盘出现时必须保留的信息、操作与阅读顺序，以及哪些区域允许重排、折叠、滚动、固定或切换呈现形式。
- 记住公共交互的语义名称、角色、值与状态，键盘顺序、焦点进入与返回、错误关联、动态播报和触控目标契约，以及高对比、减少动画、不同指针能力和辅助技术下不得丢失的任务能力。
- 记住语言、消息与格式化资源的权威和版本，缺失翻译、长文本、复数、双向文本与语义镜像规则，以及业务时间使用的服务端时钟、时区、日界线、绝对时刻、当地日期和相对时长含义与转换边界。
