# Web 工程项目记忆 · 应用结构、构建与交付治理

- 记住项目实际存在的浏览器入口、应用壳、共享布局、页面与功能模块各由谁拥有，关键用户操作从入口经路由、共享状态和适用数据契约到达何种业务结果与恢复路径，哪些入口共同复用同一业务模型与能力，以及相应公共接口、依赖方向和禁止跨越的内部边界。
- 记住目录、组件、状态逻辑、转换与副作用函数的命名和职责约定，常量与公开配置的作用域，网络、存储和订阅的适配位置，以及共享抽象服务的真实消费者与禁止扩展为全局机制的局部能力。
- 记住每个入口采用服务端渲染、构建期生成、流式呈现还是纯客户端运行，服务端、构建期与浏览器端分别拥有何种事实，以及首次呈现、序列化载荷、客户端水合和后续刷新必须保持一致的确定性输入。
- 记住应用启动时部署基路径、静态资源前缀、运行时公开配置、身份上下文、功能开关与浏览器能力的提供者和初始化顺序，以及无脚本、弱网、配置缺失、资源失败或初始化中断时仍须保留的入口、内容与恢复路径。
- 记住产品承诺的浏览器与设备矩阵、各核心任务依赖的运行能力、特性检测和基础退化路径，以及干净环境可重复构建、浏览器公开配置、依赖锁定与退出、拆包预算和调试映射受控保存的交付边界。
