# Web 工程项目记忆 · 组件与视觉体系

- 记住基础原语、通用交互、业务组件和页面组合的分层与真实消费者，共享组件稳定的属性、事件、插槽、受控状态和允许组合，以及组件实例和列表项依赖的数据身份、请求、监听、订阅与卸载清理契约。
- 记住设计令牌、主题语义、CSS 来源、级联顺序和作用域的权威关系，第三方样式的限定覆盖点，以及排版、间距、内容宽度、控件高度、图标、圆角、颜色和反馈状态采用的统一尺度与角色。
- 记住已确认产品内容语义的权威来源及用户可见文字从用户情境、业务对象、任务、结果和下一步呈现的边界，主次动作的位置、名称、图标、顺序和可见性，同类控件在悬停、焦点、按下、禁用、错误与加载时的交互语义，以及异步反馈、动态内容、浮层、粘性区域和滚动主体必须维持的尺寸稳定、关闭方式与焦点恢复关系。
