# Web 工程项目记忆 · 路由、状态与数据

- 记住每项核心任务的稳定 URL、路径参数、查询参数与片段分别表达何种资源或任务状态，由哪一层校验、规范化和生成，以及哪些状态可分享、刷新、书签恢复，哪些敏感或短暂状态不得进入地址。
- 记住路由所有者、应用壳层级、主导航、当前位置、页面标题和返回关系，以及地址栏直达、站内导航、外部深链、未知资源、无权访问、认证失效、永久删除与系统故障各自应返回的页面、状态或重定向。
- 记住列表进入详情再返回、浏览器前进后退、刷新和部署回退时必须恢复的筛选、排序、分页、展开、选中项与滚动位置，以及未提交编辑或进行中操作在离开、重入和会话恢复时的保留、舍弃与继续规则。
- 记住远端业务事实、查询缓存、表单草稿、局部交互和跨页面任务状态分别由哪个 store、URL、组件或服务端资源拥有，其唯一权威、派生关系、同步方向、存活期及在成功、取消、离开和错误后的重置条件。
- 记住账户、租户、角色和匿名会话的客户端隔离键与传播方式，以及登录、退出、身份切换、权限变化、令牌失效和跨标签页同步时哪些缓存、草稿、待处理写入、订阅与连接必须清理、失效或重建。
- 记住每类浏览器持久化数据究竟是设置、缓存、草稿还是离线副本，使用何种存储与结构版本，如何迁移、校验和损坏恢复，其容量、驱逐、多标签并发与身份作用域边界，以及恢复联网或会话重建后同服务端权威收敛的规则。
- 记住共享请求、传输模型转换和查询缓存的所有者，缓存键完整覆盖的参数、账户、租户与权限作用域，写入影响的失效或局部更新范围，以及初次加载、保留旧内容的刷新、分页追加和局部更新分别如何呈现。
- 记住读取取消与去重、陈旧响应丢弃、不可并发写入排序、批量资源上限、瞬态故障重试、幂等保证、乐观更新回滚和冲突裁决的项目约定，尤其是副作用不可逆或结果未知时禁止自动重放的边界。
- 记住实时连接和订阅由谁创建、共享与释放，消息稳定身份、重复、乱序、缺口和快照版本如何处理，断线重连从何处补齐并同权威状态收敛，以及通道可用、消息已达与数据完整三者不可混同的边界。
