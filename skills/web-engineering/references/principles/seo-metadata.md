# Web 工程 · SEO 与页面元数据

### SEO 与页面元数据

- 只有公开、无需认证且具有独立搜索价值的页面进入索引；筛选组合、分页和重复变体是否收录应依据内容独立性决定。
- 可索引页面的主体与关键元数据应存在于抓取时的文档中；客户端后置修改不能成为搜索引擎获得唯一内容语义的前提。
- 每个规范资源保持唯一地址，语言变体、站点地图、重定向和规范声明相互一致；结构化数据只能描述页面真实可见内容。
- 创建、重命名、临时缺失、永久删除和未知路径应返回符合资源生命周期的状态，不得全部用成功应用壳掩盖。
- 分享预览使用公开、稳定且能真实呈现对象的标题、说明和媒体；私有内容、账户状态和内部标识不得泄漏到页面源码。
