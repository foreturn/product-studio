# Web 工程 · 测试与可观测性

### 测试与前端可观测性

- 测试层级应由风险只能在哪一层暴露决定：纯规则、组件行为、跨模块集成、浏览器语义和真实用户路径分别使用最低充分证据。
- 断言应面向用户可见结果、语义和稳定契约，不依赖私有调用、临时节点层级和脆弱选择器；替身数据必须遵循真实边界。
- 布局、焦点、导航历史、浏览器存储、多上下文并发和资源生命周期需要真实浏览器验证；截图只能补充视觉差异。
- 测试应覆盖成功、取消、乱序、重复、离线、错误和恢复，保持数据隔离与可重复性，并明确模拟环境不能证明的外部行为。
- 运行观测只采集能定位版本、页面、操作和故障影响的信号；错误、性能和网络事件应可关联，同时限制数量和噪声。
- 遥测在采集前脱敏并尊重用户选择；完整地址参数、凭据、正文和用户内容不得进入日志，观测失败不能阻塞业务。
