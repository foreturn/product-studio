# 发布工程项目记忆

## 核心记忆

### 发布单元、范围与版本权威

- 记住哪些组件、配置、数据变化、共享依赖和消费者共同构成一个发布单元，哪些单元共享或独立生命周期，以及包含与排除每个单元所依据的真实消费关系。
- 记住每个发布单元的版本权威字段、仓库与工作区范围、生成输入、依赖锁、嵌套仓库和同步关系，以及正式 Tag、修订、版本文本和可变开发身份各自表达的不同语义。
- 记住准备、构建、验证、分发和目标环境生效这些状态的完成条件与权威查询入口，哪些消费者和渠道据何种稳定规则识别发布对象，以及任一输入漂移后旧候选如何失效。

### 不可变候选、构建与来源证明

- 记住正式构建的全部受控输入、工具链、环境与可复现条件，源快照、依赖解析、构建过程和输出制品如何以摘要或等价不可变身份绑定，哪些本机状态与浮动值不得参与。
- 记住同一候选跨环境只晋级同一字节的规则，可变别名、缓存、名称和版本文本为何不承担权威身份，以及重新构建、覆盖或重用已有正式标识会形成何种新对象或被禁止的行为。
- 记住组件清单、签名、扫描、来源与构建证明如何绑定到实际制品，字节不可完全复现时必须解释的输入输出差异，以及平台通道和安全来源政策分别由哪个专业拥有。

### 流水线、缓存与技术门禁

- 记住各流水线阶段的触发、输入、输出、执行身份、失败语义和外部副作用，阶段之间的真实依赖，以及哪些失败必须阻止后续上传、标记、部署或其他危险写入。
- 记住依赖、构建和测试缓存所覆盖的全部结果影响维度、共享范围与失效条件，允许复用的候选身份，以及跨工具链、配置、平台或不受信上下文绝不能误命中的边界。
- 记住每项技术门禁实际证明的质量、安全、兼容或来源要求，允许失败时明确不影响的发布判据，自动重试可用于的幂等瞬态动作，以及未知结果或非幂等写入的人工确认入口。

### 环境、配置、秘密与依赖映射

- 记住每个目标环境的账户、区域、部署单元、网络、证书、容量、外部依赖和运行身份，制品身份如何在环境中确认，以及临时、预发布和正式环境之间不能互相外推的差异。
- 记住环境配置的 Schema、作用域、默认值、版本兼容、审计与回退关系，环境专属配置同不可变制品的分离方式，以及隐式默认或配置缺失时必须停止推进的边界。
- 记住秘密只以何种受控引用和最小权限注入，发布过程不得读取或固化的值，以及目标依赖、配额、证书或配置的局部查询只支持何种账户、区域与时间范围的结论。

### 混合版本、契约与数据迁移

- 记住服务、客户端、数据、消息和外部消费者在非原子更新期间必须支持的新旧组合、兼容期限与演进顺序，何时先扩展能力、迁移使用者、再收缩旧契约。
- 记住数据回填、格式转换和长时迁移的批次、幂等、暂停、断点恢复、完整性校验、在线负载与进度观察规则，以及哪些动作不能藏在应用启动或自动部署中。
- 记住产生新数据或外部副作用前必须验证的回滚能力，旧版本无法理解新状态时采用的前滚或补偿路径，以及旧消费者退出、迁移完成和旧结构删除的权威判据。

### 渐进发布、功能暴露与容量保护

- 记住各工作负载按状态性、启动行为、故障影响和恢复能力采用的滚动、蓝绿、金丝雀或其他策略，阶段顺序、风险分区、最大影响范围和旧容量释放条件。
- 记住每次扩大、暂停与完成所依赖的候选专属技术信号、业务结果、样本和观察窗口，连接、队列、缓存与下游依赖的容量保护，以及不受流量比例控制的后台任务和外部副作用。
- 记住代码部署同功能暴露分离时的开关权威、安全默认、身份与租户作用域、组合限制、可观察状态和清理条件，以及控制机制不能替代的产品资格与服务端授权。

### 运行身份、健康观察与发布验证

- 记住目标环境实际运行的制品、配置和依赖身份如何查询，进程存活、流量就绪、关键用户结果与持久副作用分别由哪些静态、自动化或真实环境证据确认。
- 记住候选与基线的错误、延迟、资源、积压和业务成功信号，门禁阈值、样本、排除项和触发动作，以及启动、缓存、队列、长任务和流量周期决定的最短观察窗口。
- 记住健康端点、流水线成功、无错误日志、低样本或单一区域各自不能证明的范围，哪些用户旅程、数据不变量、外部渠道和消费者行为必须在目标边界内另行验证。

### 停止、回滚、前滚与恢复

- 记住每个发布阶段在何种身份不符、门禁失败、信号矛盾、容量不足或业务异常下必须停止扩大，停止动作、证据保留、观察窗口与最大影响边界。
- 记住可回滚的制品、配置、流量和开关，旧版本兼容当前数据与契约的前提，以及迁移、外部通知、支付、任务和其他不可逆副作用只能采用前滚、补偿或人工恢复的边界。
- 记住恢复时制品、配置、流量、任务、缓存、积压、数据和外部依赖的处理顺序，恢复入口与权限，以及重新确认对象身份、关键用户结果、数据不变量和稳定观察期的判据。

### 分发渠道、热修复、消费者与操作授权

- 记住各仓库、注册表、插件源、应用商店、区域和分发渠道解析到不可变制品的关系、同步与缓存行为、发现或安装契约，以及上传、审核、可获取和用户实际获得能力的不同状态。
- 记住紧急缓解、配置改变、回滚和代码热修复的爆炸半径、可逆性、最小差异与必要验证，生产修复回归主线和消除长期分叉的责任，以及各类消费者的升级、重新授权和兼容通知期限。
- 记住提交、推送、Tag、上传、晋级、部署、迁移、切流和恢复分别需要的对象与环境授权、最小身份、并发隔离和防重复机制，以及审计必须记录而不得包含秘密或生产敏感载荷的动作与结果。
