# release-engineering 当前产品事实规则

## 所有权与稳定位置

`release-engineering` 只拥有版本与发布制品身份、来源绑定、晋级、环境映射、发布门禁、兼容执行、停止恢复和分发兼容的稳定发布契约。CI 执行域与制品传输存储通道机制归 `platform-engineering`，来源准入、签名完整性与风险例外政策归 `security-engineering`；本册仅引用这些机制与政策，不复制正文。它不拥有产品目标、实现语义、数据库设计、质量标准或某次发布的运行状态。

稳定事实册为 `docs/product-studio/<product-id>/release-engineering.md`。`product-id` 必须由产品入口、元数据、项目根、发布单元和消费者共同确认；归属不唯一时不得读取、创建或修改候选事实册。

## 事实类型索引

1. 版本权威与 Tag 政策
2. 不可变制品、来源绑定与晋级
3. 环境身份、配置与依赖映射
4. 渐进发布、健康与观察门禁
5. 兼容迁移、停止与恢复契约
6. 分发渠道与消费者兼容

## 通用入册门禁

- 候选事实必须是可交付终态中当前已经成立的受支持语义，不得是计划、目标、进度、审批、授权、事故状态或一次发布结论。
- 候选事实必须跨局部重构、具体版本和单次发布仍稳定且有意义，且不能由一个清单、一次查询或普通命令低成本直接生成。
- 候选事实必须会改变后续发布对象识别、门禁、兼容、停止或恢复判断，重新发现完整语义具有明显成本。
- 候选事实必须具有唯一 Owner；发布册只引用数据库、安全、质量等权威契约，不复制其政策或实现正文。
- 候选事实必须由当前权威仓库、制品系统、渠道、配置或受控环境直接支撑，并能够沿权威入口重复复核；事实册不能自证。
- 当前版本、Tag、digest、实例、流量、健康值、容量、迁移游标、rollout 进度、核验时点和单次结果只用于本轮报告，不进入事实册。
- 秘密、密钥、令牌、签名材料、用户或生产数据、生产授权、原始载荷、任务历史和可利用细节永不入册。

## 主题表达规则

主题以稳定发布语义命名，不含日期、版本、任务号、环境实例或动作前缀。正文不绑定统一 Markdown 标题、栏位、顺序或句数；可依事实类型与检索需要使用段落、列表、表格或局部小节。无论表达形式如何，都必须能够辨认当前成立的语义、权威依据、适用或影响边界、复核方式与失效触发；由命中的事实类型决定具体内容，不用空栏或占位符凑格式。

一个主题只容纳共同检索、共同变化的语义。清单副本、命令流水、运行查询结果、发布记录和证据叙事不得复制进正文。

## 动作语义

- `ADD`：候选通过全部入册门禁，且同一合并键尚无主题。
- `UPDATE`：同一主题的当前语义、依据、影响边界或复核入口发生实质变化；原位保留唯一当前版本。
- `DELETE`：当前权威证明确认事实或最后消费者已经消失；直接删除，不留墓碑。
- `NO_CHANGE`：已沿权威入口复核，但稳定语义没有新增、改变或消失；事实册字节保持不变。

任一动作的归属、证据或写权限不足时不得写入事实册，具体收束结果只依公共终态协议判定。

## 事实类型

### 版本权威与 Tag 政策

- **入册条件**：一个发布单元具有后续发布反复依赖的版本权威、载体同步、正式 Tag 语义或不可变指向规则，且完整关系无法从单个清单直接推导。
- **主题合并键**：`发布单元 + 版本权威关系 + Tag 语义`；共同表达一个身份契约的载体合并，不按具体版本或 Tag 建题。
- **当前事实写法**：写明权威载体、派生关系、同步不变量、正式与开发身份边界、Tag 指向保证及消费者限制，不写当前版本值。
- **权威依据**：引用清单、构建或发布配置、版本校验入口和 Tag 规则；历史 Tag、CHANGELOG 或事实册自身不能续证。
- **影响边界**：列出适用包、插件、应用、镜像、渠道和消费工具，并明确独立生命周期单元与开发快照不适用之处。
- **复核入口**：解析所有权威载体并检查同步和指向不变量；发布单元、载体、Tag 语义或消费者变化时重审。
- **变更规则**：稳定身份契约首次成立为 `ADD`；权威关系、同步、Tag 语义或边界变化为 `UPDATE`；发布单元与最后消费者退役为 `DELETE`。
- **排除项**：不记录当前版本、候选版本、具体 Tag、提交列表、发布日期、版本讨论、一次命令或可由清单直接生成的值。

### 不可变制品、来源绑定与晋级

- **入册条件**：后续发布必须复用同一源快照绑定、不可变制品身份、证明入口、仓库或跨环境晋级语义，违反会失去验源或审计能力。
- **主题合并键**：`发布单元 + 制品族 + 来源绑定与晋级边界`；同一制品的构建、身份、证明和晋级关系合并。
- **当前事实写法**：写明源快照与构建、制品及证明的绑定不变量，仓库和晋级限制、保留边界，以及安全准入政策的权威引用，不复制其正文。
- **权威依据**：引用构建流水线、锁定输入、制品清单、仓库与晋级配置、证明验证入口和安全政策入口，不引用一次输出。
- **影响边界**：列出制品仓、环境类别、平台、架构、渠道和消费者，并明确本地临时构建、可变别名和未验收制品不受保证。
- **复核入口**：从不可变身份反查源快照、构建与证明绑定，并验证晋级不重建；快照算法、构建系统、身份算法、证明入口或晋级关系变化时重审。
- **变更规则**：稳定绑定首次成立为 `ADD`；制品族、绑定、身份、证明入口、仓库、晋级或保留语义变化为 `UPDATE`；制品族与最后消费者退役为 `DELETE`。
- **排除项**：不记录当前 digest、签名、SBOM、扫描结果、构建日志、可变 Tag、缓存路径、私钥、令牌或安全阈值与风险例外正文。

### 环境身份、配置与依赖映射

- **入册条件**：环境类别与部署单元之间存在后续发布必须复用的稳定定位、配置、秘密引用、依赖或身份查询关系，且不能从单一部署文件完整重建。
- **主题合并键**：`环境类别 + 部署单元 + 映射契约簇`；共同决定同一部署身份与前置的语义合并，不按实例或区域快照建题。
- **当前事实写法**：写明环境类别、部署单元、配置和秘密引用的语义、外部依赖边界、稳定身份字段、映射或不一致判定及差异限制。
- **权威依据**：引用 IaC、部署清单、配置 Schema、环境模板、依赖检查和只读身份查询入口；秘密只记引用契约，不记值。
- **影响边界**：列出适用环境类别、区域边界、部署单元、数据或外部依赖和消费该映射的判断，明确临时沙箱与未纳入对象。
- **复核入口**：渲染或解析配置并用只读入口核对身份与依赖关系；Schema、定位字段、部署拓扑、依赖或秘密引用语义变化时重审。
- **变更规则**：稳定映射首次成立为 `ADD`；定位、配置语义、依赖、身份字段、判定或适用边界变化为 `UPDATE`；环境契约或最后消费者退役为 `DELETE`。
- **排除项**：不记录当前版本、digest、实例、流量、健康、容量、查询原始输出、秘密值、个人配置、完整拓扑或临时环境差异。

### 渐进发布、健康与观察门禁

- **入册条件**：部署顺序、风险分区、扩大或暂停条件、健康信号、业务验证和观察语义是后续发布反复使用的稳定门禁组合。
- **主题合并键**：`发布对象 + 风险边界 + 门禁目的`；共同决定一次扩大或完成判断的策略、信号和观察规则合并。
- **当前事实写法**：写明风险分区、进入条件、最大影响边界、稳定信号与业务结果引用、聚合和观察语义、扩大暂停及完成判据，不写即时数值。
- **权威依据**：引用部署与流量配置、质量门禁、指标或探针定义、业务校验入口和稳定运行手册，不引用截图或发布记录。
- **影响边界**：列出环境类别、区域或租户边界、入口流量、后台任务、数据和外部副作用，并明确不受控制路径与证据外推限制。
- **复核入口**：检查策略和门禁可执行性，验证信号定义及停止入口；拓扑、风险分区、信号、观察语义、业务结果或任务副作用变化时重审。
- **变更规则**：稳定门禁组合首次成立为 `ADD`；分区、条件、信号、观察、停止或完成语义变化为 `UPDATE`；门禁与最后消费者退役为 `DELETE`。
- **排除项**：不记录当前灰度比例、rollout 进度、即时指标、健康结论、观察计时、审批、操作者、一次告警、截图或发布命令流水。

### 兼容迁移、停止与恢复契约

- **入册条件**：发布跨越长期兼容窗口、数据或协议演进、不可逆副作用，且后续操作必须复用稳定执行不变量、停止条件、恢复能力与退出触发。
- **主题合并键**：`发布单元 + 兼容或故障边界 + 恢复能力`；共同约束同一演进或故障的执行、停止与恢复语义合并。
- **当前事实写法**：引用数据库或架构权威契约，写明发布侧支持的版本组合、执行不变量、停止触发、可逆对象、恢复入口、不可恢复边界和兼容退出条件。
- **权威依据**：引用已确认迁移入口、兼容矩阵、部署控制、备份或恢复手册、任务控制和演练入口；不复制数据库方案或一次执行记录。
- **影响边界**：列出读写版本、部署单元、存储、队列、缓存、外部系统和最大影响范围，明确代码回滚不能撤销的数据与副作用。
- **复核入口**：在安全环境复核版本组合、停止和恢复入口及退出条件；权威迁移契约、兼容消费者、工具、备份、拓扑或副作用变化时重审。
- **变更规则**：可复用兼容与恢复契约首次成立为 `ADD`；支持组合、不变量、触发、入口、恢复范围或退出条件变化为 `UPDATE`；兼容窗口关闭且最后消费者消失或能力退役为 `DELETE`。
- **排除项**：不记录迁移阶段、回填游标、批次进度、当前兼容状态、事故时间线、生产数据、连接秘密、临时命令或未经演练的恢复承诺。

### 分发渠道与消费者兼容

- **入册条件**：同一发布单元通过多个渠道或客户端形态分发，且稳定身份、入口、同步和兼容关系会约束后续发布判断。
- **主题合并键**：`发布单元 + 渠道集合 + 消费者兼容边界`；共享同一身份和生命周期的渠道合并，独立生命周期分题。
- **当前事实写法**：写明渠道身份关系、入口与同步不变量、消费者支持边界、发现或安装语义，以及一个渠道的证据不能外推至其他渠道的限制。
- **权威依据**：引用各渠道清单、包元数据、发布流水线、消费者兼容声明和安装发现校验入口，不引用宣传页面或一次安装日志。
- **影响边界**：列出消费平台、客户端类别、渠道、包或插件身份和共享制品，并明确未分发、未安装或未验证的表面。
- **复核入口**：解析比较渠道身份、入口和兼容声明，并按渠道验证实际发现；清单格式、身份关系、客户端契约或共享制品关系变化时重审。
- **变更规则**：稳定多渠道契约首次成立为 `ADD`；身份、入口、同步、兼容或验证边界变化为 `UPDATE`；渠道或最后消费者永久退役为 `DELETE`。
- **排除项**：不记录当前渠道版本、安装量、审核进度、发布状态、个人缓存路径、用户安装清单、市场文案或单次安装结果。

## 全册安全与删除规则

- 禁止写入秘密、凭据、密钥、令牌、签名材料、个人或用户数据、生产数据、原始载荷、授权、任务历史、原始差异、长日志和可利用细节。
- 同一正文只属于一个 Owner；发布册只保存发布语义及权威引用，不复制数据库方案、安全政策、质量阈值或其他事实正文。
- 删除必须由当前权威证明确认事实或最后消费者消失，不以一次失败、查询不可得、发布结束、版本变化或工具故障推断失效。
- 删除最后主题时删除空事实册；产品目录没有其他事实册时才删除空目录。历史由 Git、制品、渠道、流水线和事件系统承担。
