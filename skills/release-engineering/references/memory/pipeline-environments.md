# 发布工程项目记忆 · 流水线、环境与迁移

- 记住各流水线阶段的触发、输入、输出、执行身份、失败语义和外部副作用，阶段之间的真实依赖，以及哪些失败必须阻止后续上传、标记、部署或其他危险写入。
- 记住依赖、构建和测试缓存所覆盖的全部结果影响维度、共享范围与失效条件，允许复用的候选身份，以及跨工具链、配置、平台或不受信上下文绝不能误命中的边界。
- 记住每项技术门禁实际证明的质量、安全、兼容或来源要求，允许失败时明确不影响的发布判据，自动重试可用于的幂等瞬态动作，以及未知结果或非幂等写入的人工确认入口。
- 记住每个目标环境的账户、区域、部署单元、网络、证书、容量、外部依赖和运行身份，制品身份如何在环境中确认，以及临时、预发布和正式环境之间不能互相外推的差异。
- 记住环境配置的 Schema、作用域、默认值、版本兼容、审计与回退关系，环境专属配置同不可变制品的分离方式，以及隐式默认或配置缺失时必须停止推进的边界。
- 记住秘密只以何种受控引用和最小权限注入，发布过程不得读取或固化的值，以及目标依赖、配额、证书或配置的局部查询只支持何种账户、区域与时间范围的结论。
- 记住服务、客户端、数据、消息和外部消费者在非原子更新期间必须支持的新旧组合、兼容期限与演进顺序，何时先扩展能力、迁移使用者、再收缩旧契约。
- 记住数据回填、格式转换和长时迁移的批次、幂等、暂停、断点恢复、完整性校验、在线负载与进度观察规则，以及哪些动作不能藏在应用启动或自动部署中。
- 记住产生新数据或外部副作用前必须验证的回滚能力，旧版本无法理解新状态时采用的前滚或补偿路径，以及旧消费者退出、迁移完成和旧结构删除的权威判据。
