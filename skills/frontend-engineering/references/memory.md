`frontend-engineering` 是前端实现事实的唯一语义 Owner。稳定 locator 为 `<Git仓库根>/docs/product-studio/<product-id>/frontend.md`，技能或目录改名不改变该位置。本册表达当前仍成立、后续前端编码需要复用的实现语义，不复制产品政策、体验方案、服务端契约正文、安全政策或发布记录。

## 产品定位与事实实例

- `product-id` 在同一 Git 仓库内必须唯一、稳定且可安全作为单级目录名。
- 依据用户范围、仓库原生产品身份、入口与元数据、相关项目根、前端代码及实际消费关系共同确认，不从目录名机械推导。
- 多产品仓库逐产品隔离；归属不能唯一确认时，不读取或写入候选事实册，也不创建目录。
- 首次出现有效 `ADD` 时同次创建产品目录和 `frontend.md`；最后一个主题被 `DELETE` 后移除该册，产品目录没有其他事实文件时才移除空目录。

## 统一主题格式

每个主题使用简短业务语义命名，不含类型前缀、路径、日期、任务号或变更动作。一个主题只表达一组共同检索、共同变化的事实。

```markdown
# frontend-engineering 当前产品事实

## <稳定事实主题>

- **当前事实**：<必要条件、当前前端行为、用户可见结果与明确边界>
- **权威依据**：<一至三个仓库相对路径#精确 Route、Component、Hook、Adapter、Token 或配置 Symbol>
- **影响边界**：<用户任务、页面、组件、浏览器、视口、输入方式、数据状态、不得破坏关系与明确不适用处；无则写“无”>
- **复核入口**：<可重复测试、真实浏览器入口、命令或检查，含关键状态、断言、适用环境、未覆盖边界与重审触发>
```

四栏只陈述当前语义。权威路径必须存在且位置可定位；复核入口必须说明能证明什么及不能证明什么。只读任务或未获文件写入授权时，只报告候选主题、动作与证据，不修改事实册。写入必须由当前代码、配置或权威契约和风险相称的可重复验证共同支撑；不得以设计稿、进行中实现、单张截图或推断替代当前证据。只修改发生实质变化的主题，不顺带排序、润色或改写无关内容。

## 事实类型：路由与任务实现

- **入册条件**：当前前端通过稳定入口、路由守卫、页面壳或任务页面实现某项用户任务，并对深链、返回、权限可见性、参数和完成去向形成可复用行为；单个内部组件挂载不入册。
- **主题合并键**：以“用户任务 + 路由入口族 + 完成或返回边界”合并；同一任务的列表、详情和编辑路由若共同演进可同题，不按路径字符串或页面文件拆分。
- **当前事实写法**：写明用户从何入口在何种身份与参数下进入、页面壳与任务职责、守卫或重定向、深链／刷新／返回结果、完成去向及明确不支持入口。
- **权威依据**：优先引用路由定义、页面组件、Route Guard、Loader、导航 Hook 和路由集成测试；菜单文案或设计稿不能单独作为入口依据。
- **影响边界**：列出用户任务、身份、页面、嵌套路由、URL 参数、浏览器历史、深链消费者和依赖的服务端能力，说明非 Web 入口不在本类。
- **复核入口**：使用路由测试或真实浏览器按代表身份与数据验证直接访问、导航、刷新、返回、无权访问和完成去向，并注明未覆盖的部署 base path 或真实身份系统。
- **变更规则**：`ADD` 用于新增已实现且有真实消费者的稳定任务入口；`UPDATE` 用于路径、参数、守卫、页面职责、导航结果、依据或边界改变；`DELETE` 用于入口、任务或兼容责任消失；`NO_CHANGE` 用于页面文件或路由库重构但四栏行为不变。
- **专属禁项**：不抄录完整路由表、菜单清单或页面文件树，不记录未实现页面、临时调试路由、视觉稿流程、历史 URL 迁移过程或服务端权限政策正文。

## 事实类型：共享组件与设计令牌

- **入册条件**：当前存在被多个真实场景复用的共享组件、交互原语或设计令牌，并对变体、状态、语义与使用边界形成稳定实现契约；单页面私有样式不入册。
- **主题合并键**：以“共享语义原语 + 变体或令牌族 + 消费边界”合并；共同变化的组件与令牌写成一个主题，不按每个 CSS 类、色值或 Story 拆分。
- **当前事实写法**：写明共享原语解决的任务、公开变体与状态、令牌映射、内容与组合边界、默认无障碍语义、真实消费者及明确不适用场景。
- **权威依据**：优先引用组件公开 API、实现 Symbol、主题或令牌定义、样式契约、Story／视觉回归和组件测试；截图或设计文件不能单独证明当前实现。
- **影响边界**：列出消费页面、组件、主题、品牌模式、密度、状态、输入方式和不得破坏的公共 API；产品体验语义与具体页面布局不在本类复制。
- **复核入口**：运行组件测试、Story、视觉回归或真实页面检查默认与关键变体、禁用／加载／错误状态、主题和输入方式，并说明截图环境与浏览器覆盖。
- **变更规则**：`ADD` 用于形成有多个真实消费者的稳定共享原语；`UPDATE` 用于公开变体、状态、令牌、语义、消费者、依据或复核边界改变；`DELETE` 用于公共原语及最后消费者消失；`NO_CHANGE` 用于内部 DOM、CSS 或构建方式变化但公共四栏不变。
- **专属禁项**：不记录组件、图标、令牌或色值全量清单，不把页面私有样式、未来复用设想、设计稿规范、单张快照或审美偏好写成本类事实。

## 事实类型：客户端状态所有权

- **入册条件**：当前前端对一组业务相关状态明确由 URL、服务端缓存、全局 Store、页面容器、表单或组件局部持有，并具有稳定的初始化、同步、失效、持久化或清理语义。
- **主题合并键**：以“状态语义 + 唯一所有者 + 生命周期边界”合并；同一所有者下共同初始化和清理的状态可同题，不按每个字段、Selector 或 Hook 拆分。
- **当前事实写法**：写明状态代表什么、权威所有者、初始化来源、更新入口、派生关系、缓存或持久化范围、失效与清理时机，以及哪些副本不得作为权威。
- **权威依据**：优先引用 Store、Context、Query 配置、路由参数、容器 Hook、持久化 Adapter 和状态测试；组件读取位置不能单独证明所有权。
- **影响边界**：列出页面、组件、路由、用户或租户作用域、会话、标签页、服务端数据源和并行更新场景。
- **复核入口**：测试初始化、更新、导航、刷新、身份切换、失效、并发响应和卸载清理，断言单一权威与用户可见结果，并注明跨标签页或真实网络未覆盖处。
- **变更规则**：`ADD` 用于当前稳定状态所有权首次值得跨任务复用；`UPDATE` 用于所有者、生命周期、持久化、失效、作用域、依据或复核边界改变；`DELETE` 用于状态或最后消费者消失；`NO_CHANGE` 用于 Store 库、Hook 名称或内部数据结构替换但所有权语义不变。
- **专属禁项**：不抄录 Store 字段、Action、Query Key 或组件状态全量清单，不记录瞬时调试值、未实施状态架构、服务端数据所有权正文或将派生副本误写成权威状态。

## 事实类型：请求适配与错误映射

- **入册条件**：当前前端对服务端或外部接口实施稳定的请求组装、响应归一、取消竞态、身份上下文、缓存适配或错误到用户状态的映射，且多个调用点依赖该行为。
- **主题合并键**：以“业务请求族 + Adapter 边界 + 用户可见结果”合并；共享输入输出与错误映射的调用同题，不按每个 HTTP 方法、类型或错误码拆分。
- **当前事实写法**：写明调用时机、参数与身份来源、响应归一结果、取消或陈旧响应处理、业务拒绝／网络／超时／会话错误映射、重试条件及明确不处理的异常。
- **权威依据**：优先引用请求 Adapter、API Client、Query／Mutation Hook、错误归一器、拦截器和契约测试；服务端文档只说明依赖，不能替代当前前端实现依据。
- **影响边界**：列出用户任务、页面、调用点、身份与租户、缓存、并发请求、服务端契约版本和用户可见状态。
- **复核入口**：使用 Adapter 单元测试、Mock Server 集成测试或浏览器网络场景验证成功、业务拒绝、会话失效、超时、离线、取消、乱序响应与重试，并区分模拟与真实服务证明。
- **变更规则**：`ADD` 用于当前已有多个真实消费者的稳定适配或错误映射；`UPDATE` 用于参数来源、归一结果、错误映射、竞态策略、消费者、依据或复核边界改变；`DELETE` 用于 Adapter 与最后消费者消失；`NO_CHANGE` 用于 HTTP 库或生成客户端变化但四栏语义不变。
- **专属禁项**：不复制完整 API、DTO 或错误码清单，不写服务端契约正文、访问令牌、抓包数据、临时 mock、一次网络失败或未实施重试方案。

## 事实类型：表单输入与恢复

- **入册条件**：当前前端对高价值表单或输入任务具有稳定的字段映射、默认、客户端校验、提交、错误定位、数据保留、草稿、取消或恢复行为，且后续修改需要保持这些语义。
- **主题合并键**：以“用户输入任务 + 表单生命周期 + 提交目标”合并；共同初始化、校验和恢复的一组字段写成一个主题，不按字段或校验规则逐项拆分。
- **当前事实写法**：写明表单适用对象、初始化与默认来源、关键派生或条件输入、校验时机、提交与重复防护、失败后的数据和焦点、取消／草稿／恢复结果及敏感字段例外。
- **权威依据**：优先引用表单容器、Schema、输入 Adapter、提交 Hook、草稿或持久化实现、错误摘要与表单测试；设计稿或后端字段存在不能单独证明前端行为。
- **影响边界**：列出角色、页面、创建／编辑模式、数据状态、浏览器刷新、导航离开、服务端校验、敏感信息和输入方式。
- **复核入口**：测试默认、条件字段、即时与提交校验、服务端错误、重复提交、失败保留、刷新或返回恢复、取消和焦点定位，并注明真实浏览器、自动填充或辅助技术覆盖。
- **变更规则**：`ADD` 用于当前稳定输入与恢复契约首次具备复用价值；`UPDATE` 用于初始化、校验、提交、数据保留、恢复、作用域、依据或复核边界改变；`DELETE` 用于表单任务与最后消费者消失；`NO_CHANGE` 用于表单库或内部字段组织变化但用户四栏语义不变。
- **专属禁项**：不抄录完整字段、校验消息或 Schema 清单，不保存用户输入样本、敏感值、临时草稿内容、未实施自动保存目标或把产品字段政策复制入本类。

## 事实类型：响应式布局

- **入册条件**：当前前端针对支持的视口、容器或输入模式实施稳定的能力保留、信息重排、折叠、详情转换、滚动或密度规则，且不仅是单个偶然 CSS 值。
- **主题合并键**：以“用户任务或布局区域 + 响应行为族 + 支持场景”合并；共同重排的一组组件同题，不按媒体查询、断点或 CSS 文件拆分。
- **当前事实写法**：写明支持场景、保持的核心能力、信息优先级、重排／折叠／转详情／滚动行为、触控与键鼠差异、长内容和虚拟键盘处理及明确不支持场景。
- **权威依据**：优先引用布局组件、响应 Hook、容器或媒体查询、样式令牌、表格／导航适配和响应式测试；单张截图不能独立支撑跨视口结论。
- **影响边界**：列出页面、区域、组件、视口或容器范围、方向、输入方式、内容规模、浏览器缩放和不得静默删除的能力。
- **复核入口**：在代表性窄屏、宽屏、触控和键鼠场景检查导航、长内容、表格、滚动、虚拟键盘、缩放和方向变化，断言能力可发现与任务可完成，并说明设备覆盖。
- **变更规则**：`ADD` 用于当前稳定响应行为首次服务真实任务；`UPDATE` 用于能力保留、重排、支持范围、输入差异、依据或复核边界改变；`DELETE` 用于布局行为或最后消费者消失；`NO_CHANGE` 用于断点数值或 CSS 实现调整但四栏用户行为不变。
- **专属禁项**：不记录媒体查询、断点、尺寸或样式属性全量清单，不把“移动端隐藏”写成无替代路径的事实，不保存截图批次、视觉偏好或未实现设备目标。

## 事实类型：无障碍实现

- **入册条件**：当前前端对关键任务稳定实现语义结构、键盘操作、焦点管理、辅助名称、错误关联、动态通知、对比、缩放或等价输入，并有可重复证据。
- **主题合并键**：以“用户任务或共享原语 + 无障碍行为族 + 辅助技术边界”合并；共同焦点与语义责任的组件同题，不按每个 ARIA 属性或扫描规则拆分。
- **当前事实写法**：写明语义与阅读顺序、键盘动作、焦点进入／恢复、辅助名称、错误和状态通知、非颜色／非拖拽替代、缩放与动画行为，以及已知不适用或未覆盖边界。
- **权威依据**：优先引用语义组件、焦点 Hook、Live Region、样式令牌、无障碍测试与浏览器实现；自动扫描报告只能作为部分证据。
- **影响边界**：列出任务、页面、组件、键盘、屏幕阅读器、缩放、减少动画、触控与支持浏览器，说明平台原生或第三方组件边界。
- **复核入口**：执行语义与自动检查，并以真实键盘、焦点、缩放和适用屏幕阅读器场景验证关键路径，记录工具、浏览器、关键断言和未覆盖组合。
- **变更规则**：`ADD` 用于当前稳定无障碍实现首次可复用；`UPDATE` 用于语义、键盘、焦点、通知、替代方式、支持边界、依据或复核条件改变；`DELETE` 用于行为及最后消费者消失；`NO_CHANGE` 用于 DOM 或组件内部重构但辅助技术四栏行为不变。
- **专属禁项**：不记录 ARIA 属性、扫描告警或 WCAG 条文全量清单，不以自动扫描零告警、单一浏览器或静态截图宣称完整通过，不写未实现整改计划。

## 事实类型：浏览器性能与兼容

- **入册条件**：当前前端对关键任务实施稳定的加载、分包、渲染、虚拟化、资源、缓存、错误隔离或浏览器兼容策略，且这些语义影响后续代码组织或用户可见结果。
- **主题合并键**：以“用户任务或资源边界 + 性能／兼容机制 + 支持环境”合并；共享加载与回退责任的资源同题，不按 chunk、polyfill、指标或浏览器版本逐项拆分。
- **当前事实写法**：写明关键路径、加载与渲染策略、资源或数据规模边界、失败回退、支持浏览器／能力检测、兼容替代、已验证性能特征及明确不作的生产承诺。
- **权威依据**：优先引用构建配置、懒加载边界、虚拟化或缓存实现、错误边界、能力检测、兼容配置、性能测试和真实浏览器代码；构建产物大小截图只能补充。
- **影响边界**：列出路由、组件、资源、数据规模、网络条件、设备能力、支持浏览器、第三方脚本和受加载或回退影响的用户任务。
- **复核入口**：运行可重复构建、性能预算或浏览器场景，检查加载顺序、交互可用、长列表、慢网、脚本失败、能力缺失和代表浏览器，并说明硬件、缓存、网络和实验室与真实用户差异。
- **变更规则**：`ADD` 用于当前稳定性能或兼容机制首次具备复用价值；`UPDATE` 用于加载边界、规模限制、回退、支持环境、依据或复核条件改变；`DELETE` 用于机制与最后消费者消失；`NO_CHANGE` 用于打包器、依赖或实现位置变化但四栏用户行为不变。
- **专属禁项**：不记录 chunk、依赖、浏览器版本或 Lighthouse 分数全量清单，不把一次本地测量冒充生产性能，不保存制品时间戳、历史体积对比、临时兼容补丁计划或用户数据。
