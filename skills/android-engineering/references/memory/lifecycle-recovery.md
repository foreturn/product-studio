# Android 工程项目记忆 · 生命周期与状态恢复

- 记住应用冷启动和后台进程启动时依赖装配、运行时公开配置、身份上下文、功能开关与平台服务的来源和初始化次序，以及缺失、失败或重复初始化时保留的入口与禁止发生的业务副作用。
- 记住短暂交互、页面、导航图、窗口、进程和跨会话业务状态分别由哪个 Composable、ViewModel、宿主、持久层或服务端事实拥有，其存活期、派生关系和重置条件。
- 记住配置变化、方向与窗口调整、语言主题切换、后台回收和进程重建后必须恢复的稳定标识、导航、选择、输入与任务进度，以及恢复时必须重新校验的账户、版本、权限和目标有效性。
- 记住监听、系统回调、请求、媒体、游标、计时与临时资源的注册和释放边界，多窗口之间哪些状态独立、哪些事实共享，以及页面重建或窗口关闭时绝不能重复或误取消的副作用。
