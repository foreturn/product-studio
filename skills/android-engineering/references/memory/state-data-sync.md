# Android 工程项目记忆 · 状态、数据与离线同步

- 记住服务端事实、本地副本、查询缓存和界面派生状态的所有者与身份键，初次加载、保留旧内容的刷新、分页追加、空结果、部分成功和局部更新分别如何呈现。
- 记住异步工作的父子作用域、取消传播与错误去向，搜索、快速切换、顺序写入和批量读取的并发策略，以及连接失败、认证失效、限流、业务拒绝、冲突、解析失败和结果未知的稳定恢复语义。
- 记住自动重试、幂等、乐观更新和回滚的适用边界，实时连接与订阅由谁共享和释放，消息身份、重复、乱序、缺口、断线与重连后怎样同权威快照收敛。
- 记住设置、结构化业务副本、文件、缓存与敏感凭据分别使用何种存储，其稳定身份、关系、索引、账户作用域、事务、容量、驱逐、加密和备份边界。
- 记住每次本地结构或文件格式变化的版本、受支持旧状态、迁移与校验路径，失败、中断、空间不足和数据损坏时如何恢复，以及哪些数据因可重获才允许重建而不做迁移。
- 记住离线时允许继续的读取与写入、必须阻断的动作、业务变更同待同步队列的原子关系，以及联网后对稳定身份、顺序、重复、幂等、冲突、删除、部分失败和账户切换的收敛规则。
