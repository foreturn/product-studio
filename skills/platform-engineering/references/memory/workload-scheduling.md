# 平台工程项目记忆 · 工作负载与调度治理

- 记住各服务、长时进程、计划任务、一次性作业和节点级组件采用的运行形态、部署单元、状态依赖与宿主边界，以及不可变制品、入口命令和本地临时状态的关系。
- 记住启动、存活、就绪、停止接收新工作、排空和终止的实际语义，更新与缩容期间必须保护的副本、在途请求、租约和任务，以及计划任务的唯一性、幂等、重叠和过期规则。
- 记住资源请求、限制、调度约束、故障域分散和维护保护的依据，运行身份、可写范围与宿主访问的最小权限，以及启动失败、资源不足和节点维护时的确定落点。
- 记住各 CI 任务的触发来源、执行信任域、隔离方式、运行身份、网络与秘密作用域，以及不受信变更、受信构建和高权限发布步骤之间不可跨越的边界。
- 记住依赖缓存、构建缓存、工作区、日志和临时制品的身份键、共享范围、保存期限和污染清理规则，哪些输入变化必须使复用失效，哪些数据不得跨仓库、分支、租户或环境泄漏。
- 记住平台只拥有执行域与上传、下载、保存通道的边界，制品不可变身份和晋级关系由发布工程维护、来源与完整性政策由安全工程维护，以及通道不可用、上传不完整和重复执行时的确定行为。
