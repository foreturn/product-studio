# platform-engineering 当前产品事实规则

## 所有权与稳定位置

- `platform-engineering` 是产品运行底座终态语义事实的唯一 Owner；其他专业只能引用，不复制或改写本册事实。
- 本册拥有环境、IaC、运行与网络底座、工作负载身份取得和注入、CI 执行域、制品传输存储通道及操作恢复机制；发布制品身份、来源绑定与晋级归 `release-engineering`，安全准入和身份授权政策归 `security-engineering`，跨运行单元故障结构与恢复责任分配归 `software-architecture`。
- 稳定位置为 `docs/product-studio/<product-id>/platform-engineering.md`；`product-id` 必须由产品身份、运行入口、环境与资源归属共同确认，且可安全作为单级目录名。
- 多产品或共享平台仓库按真实产品归属分册；归属、环境边界或 Owner 不唯一时，不得读取候选册作为依据，也不得创建或修改事实册。
- 本册只索引当前成立的平台机制与保证，不保存资源清单、配置参数或外部状态正文。涉及长期兼容时，只记当前支持不变量、现存消费者与退出触发，不记阶段、目标态或推进进度。
- 只在本轮拥有事实文件写权限时落盘；生产观察或平台访问权限本身不授予事实册写权限。

## 事实类型索引

1. 环境、账户与身份
2. IaC 状态与生命周期
3. 网络、运行时与配置机制
4. CI 与制品通道
5. 观测、SLO 与容量
6. 韧性、灾难恢复与事故机制
7. 成本、版本与漂移

## 通用入册门禁

- **终态成立**：候选语义已由当前声明与风险相称的实态验证共同证明，不是计划、推断、临时绕行或进行中工作。
- **稳定**：候选语义预计跨越本次任务持续成立；单次执行、瞬时指标、资源快照、事故状态和阶段进度不得入册。
- **非显然**：候选语义不能从资源命名、目录、平台默认或单个声明轻易重新得出，否则无需占用事实册。
- **决策相关**：候选语义会实质改变后续平台设计、实现、运维、容量、恢复或成本判断。
- **重查昂贵**：若不索引，未来需要跨 IaC、配置、运行入口、外部平台和可重复验证才能重新确认。
- **唯一 Owner**：Git 根、当前产品、`product-id`、主题合并键和 `platform-engineering` 所有权均已唯一确认，且未在他册重复。
- **可复核**：当前仓库存在稳定权威定位，并有可重复入口验证所写机制、消费者、失败结果与适用边界。
- **安全**：候选内容已最小化并脱敏，不含秘密、个人数据、内部可利用细节、资源参数、状态正文或原始证据。

任一门禁不成立即不得写入；证据、归属或授权不足时只在本轮报告说明，不产生事实动作。声明与实态冲突时先复核权威来源，不并存互斥事实。

## 主题表达规则

- 主题以稳定平台语义命名，不含路径、日期、任务号或动作前缀；同一合并键只保留一个当前主题。
- 每个主题必须表达当前事实、权威依据、影响范围与复核方式，并写清平台机制、消费者、成立条件、明确限制、证据边界和重审触发。
- 不规定固定 Markdown H2、固定四栏、固定字段标签或统一字段顺序；可依事实类型与可读性使用段落、列表或表格。
- 表达应便于沿权威入口复核和原位合并，不按资源、账户、环境实例、探针或演练机械拆题。
- 不收录资源参数、修改摘要、过程记录、运行快照、事故状态、成本流水、时间线、责任人或待办。

## 动作语义

- `ADD`：主题合并键尚不存在，候选终态语义通过全部入册门禁且必备语义完整；新增一个当前主题。
- `UPDATE`：同一主题的当前事实、权威依据、影响范围或复核方式实质变化，且新语义通过全部门禁；原位保留唯一当前表述。
- `DELETE`：主题所述机制、保证或最后消费者已从当前产品消失；删除完整主题，不保留历史占位。
- `NO_CHANGE`：沿权威依据完整复核后必备语义均无实质变化；不得因改写表达、调整顺序或更换呈现方式触碰事实文件。

## 事实类型

### 环境、账户与身份

- **入册条件**：当前产品运行域稳定依赖环境、账户或资源身份隔离语义，且多个工作负载或运维入口必须据此选择作用域与权限。
- **主题合并键**：以“产品运行域 + 环境或账户边界 + 身份隔离不变量”合并；共同变化的环境归属与身份语义归入同题。
- **当前事实写法**：引用安全身份政策，写明环境和账户作用域、生产与非生产隔离、工作负载身份取得和注入机制、消费边界与平台失败行为，不定义主体权限或信任政策，不写标识值。
- **权威依据**：定位组织或环境声明、身份与信任策略、消费配置和跨边界拒绝验证，不复制账户、角色或权限策略正文。
- **影响边界**：列出环境、区域、资源域、工作负载、身份来源、共享平台、费用归属及明确不适用的产品。
- **复核入口**：验证身份取得、授权作用域、跨环境拒绝与审计归属，并说明无法在生产或外部身份源证明的边界。
- **变更规则**：环境归属、账户边界、身份来源、隔离语义、消费者或证据改变时 `UPDATE`；仅名称或等价实现变化时 `NO_CHANGE`。
- **排除项**：不记录真实账户号、角色或权限清单、人员、临时授权、一次登录、资源清单、环境快照和未实施组织规划。

### IaC 状态与生命周期

- **入册条件**：当前资源域由稳定声明、状态所有权与生命周期保护共同管理，未来变更必须遵守其唯一权威和创建、替换或销毁语义。
- **主题合并键**：以“资源域 + 声明或状态边界 + 生命周期不变量”合并；共同收敛和销毁的资源归入同题。
- **当前事实写法**：写明声明与状态的权威关系、所有者、并发写入边界、替换或销毁保护、手工例外及失败后的确定处置，不写资源参数。
- **权威依据**：定位 IaC 模块、状态与锁声明、生命周期保护和可重复收敛验证，不复制状态内容、计划输出或平台参数。
- **影响边界**：列出环境账户、资源域、共享模块、执行主体、有状态资产、下游工作负载及明确手工管理边界。
- **复核入口**：验证声明收敛、并发保护、导入归属、替换或销毁拒绝与恢复，并注明无权访问的实态边界。
- **变更规则**：权威关系、状态边界、所有者、保护语义、消费者或证据改变时 `UPDATE`；资源域不再由该机制管理时 `DELETE`。
- **排除项**：不记录状态正文、Provider 或资源参数、计划原文、实例标识、临时漂移、一次执行结果、手工操作历史和候选设计。

### 网络、运行时与配置机制

- **入册条件**：当前工作负载稳定依赖共同的通信、计算承载、持久存储或配置注入语义，且该机制决定启动、连接、隔离或失败结果。
- **主题合并键**：以“工作负载族 + 运行与通信边界 + 配置或存储机制”合并；共同启动、连接、持久化和失效的机制归入同题。
- **当前事实写法**：写明适用环境、入口出口与名称解析语义、运行承载、配置来源优先级、持久状态边界、身份注入、刷新和失败行为，不写具体值。
- **权威依据**：定位网络与运行声明、配置 Schema、工作负载清单、存储绑定和端到端验证，不复制地址、端口、资源配额或配置值。
- **影响边界**：列出工作负载、环境区域、调用者、外部端点类别、持久数据、配置来源、启动依赖及不适用运行形态。
- **复核入口**：验证启动终止、解析连通、隔离拒绝、配置缺失与刷新、持久化恢复和依赖故障，并注明测试环境差异。
- **变更规则**：通信、运行、存储或配置语义、消费者、身份来源、失败行为或依据改变时 `UPDATE`；内部平台替换但语义等价时 `NO_CHANGE`。
- **排除项**：不记录网络拓扑清单、地址端口、实例或卷标识、资源参数、配置或秘密值、即时副本、临时调试状态和一次故障。

### CI 与制品通道

- **入册条件**：当前构建与交付任务稳定依赖 CI 执行域或制品传输存储通道机制，且该机制决定任务隔离、通道可用性、保留或缓存边界。
- **主题合并键**：以“流水线执行域 + 制品传输存储通道 + 消费边界”合并；共同运行、传递、保存和清理的通道机制归入同题。
- **当前事实写法**：引用发布身份与安全准入主题，只写运行任务隔离、制品上传下载和存储通道、保留清理、缓存非权威角色、平台失败结果与消费者，不定义制品身份、来源绑定、完整性政策或晋级资格。
- **权威依据**：定位运行平台、构建与制品配置、身份策略、来源或完整性校验和跨任务隔离测试，不复制任务或制品内容。
- **影响边界**：列出仓库与流水线族、运行信任域、制品消费者、缓存、外部依赖、环境及生产凭据边界。
- **复核入口**：验证任务隔离、凭据拒绝、缓存污染防护、上传下载、保留清理和平台故障，并说明发布身份、安全准入与外部通道盲区。
- **变更规则**：执行域、传输存储通道、保留清理、消费者、失败行为或证据改变时 `UPDATE`；仅内部任务编排变化且契约不变时 `NO_CHANGE`。
- **排除项**：不记录制品身份、来源绑定、签名或完整性政策、晋级资格、具体构建步骤、一次流水线结果、队列状态、运行器参数、缓存键清单、制品内容、真实凭据和发布决定。

### 观测、SLO 与容量

- **入册条件**：当前用户路径或平台能力稳定依赖可观测信号、SLO 判断或容量退化机制，未来变更必须维持其测量语义与决策边界。
- **主题合并键**：以“用户路径或平台能力 + 信号与目标语义 + 容量结果”合并；共同衡量和触发决策的观测、SLO 与容量机制归入同题。
- **当前事实写法**：写明被衡量结果、信号链与关联语义、权威目标引用、容量不足时的用户或平台结果、消费者、盲区与失败处理，不写数值参数。
- **权威依据**：定位遥测 Schema、采集与查询配置、SLO 定义、容量控制和代表性信号或负载验证，不复制指标快照或阈值。
- **影响边界**：列出用户路径、服务与环境、信号消费者、共享平台、数据敏感边界、下游瓶颈、成本关系及不采集范围。
- **复核入口**：验证测试信号端到端可见、关联与缺失行为，以及代表性负载下的退化和恢复，并注明生产规模证明边界。
- **变更规则**：测量语义、权威目标、容量失败结果、消费者、盲区或证据改变时 `UPDATE`；瞬时指标变化而稳定契约不变时 `NO_CHANGE`。
- **排除项**：不记录 SLO 或容量阈值、仪表盘与告警清单、瞬时指标、原始日志、当前资源用量、压测快照和短期扩容事件。

### 韧性、灾难恢复与事故机制

- **入册条件**：当前产品运行域具备经验证的故障隔离、恢复或一般可用性事故治理机制，未来故障仍须依赖其触发、权限与关闭语义。
- **主题合并键**：以“产品运行域 + 故障或事故类别 + 恢复与治理机制”合并；共同触发、恢复和关闭的韧性语义归入同题。
- **当前事实写法**：引用架构故障域、传播关系与恢复责任主题，只写平台提供的检测、隔离、接管、恢复、切回与事故治理机制，及其操作权限、关闭条件、消费者和未覆盖故障，不复制跨单元结构正文。
- **权威依据**：定位拓扑与恢复配置、运行册、用户路径探针、受控演练和治理政策，不复制当次演练、事故记录或运行状态。
- **影响边界**：列出产品路径、环境区域、平台组件、外部依赖、响应角色类别、数据库与应用恢复边界及不覆盖故障。
- **复核入口**：通过受控故障或桌面演练验证识别、接管、隔离、恢复、切回和关闭语义，并说明未经生产演练的边界。
- **变更规则**：故障域、恢复保证、指挥权限、关闭条件、消费者或证据改变时 `UPDATE`；仅发生事故或演练而机制未变时 `NO_CHANGE`。
- **排除项**：不记录事故状态、严重度快照、时间线、人员、告警或日志、当次恢复结果、临时绕行、具体发布动作和未经验证的容灾目标。

### 成本、版本与漂移

- **入册条件**：当前资源域受稳定成本归属、版本支持或漂移治理不变量约束，且未来变更必须据此决定所有权、兼容或权威态恢复。
- **主题合并键**：以“资源或平台域 + 成本、版本或漂移不变量 + 消费边界”合并；共同治理与退出的语义归入同题。
- **当前事实写法**：写明成本归属与单位驱动语义、当前支持不变量、现存消费者、权威声明态、漂移分类、例外与退出触发，不写数值或版本清单。
- **权威依据**：定位成本归属、生命周期与支持政策、版本约束、漂移检测和收敛验证，不复制账单、资源参数或外部状态。
- **影响边界**：列出账户环境、资源域、费用归属、有状态资产、平台消费者、有效例外及明确不适用资源。
- **复核入口**：验证归属完整性、支持边界、权威态识别、漂移分类与收敛结果，并说明价格或外部服务不能由仓库证明的部分。
- **变更规则**：归属语义、支持不变量、消费者、权威态、例外或退出触发改变时 `UPDATE`；治理义务消失时 `DELETE`。
- **排除项**：不记录账单明细、预算或异常阈值、Provider 与资源参数、版本清单、临时资源、当前漂移快照、采购过程和节省待办。

## 全册安全与删除规则

- 不记录真实账户号、凭据、令牌、密钥、连接串、个人数据、生产拓扑弱点、完整状态、原始日志或可直接利用的信息。
- 权威依据只写仓库相对路径与精确模块、资源声明、配置或测试位置；不得复制 Provider、资源参数、状态正文、内部拓扑或外部原始证据。
- 删除前确认终态语义、最后消费者、退出触发和所有当前依据均已消失；不因文件改名、一次探针失败或平台暂时不可达而误删。
- 删除最后主题时移除事实文件；仅在产品目录无任何 Owner 事实文件时才移除产品目录，不留下空册或空目录。
- 同一事实不得复制到其他 Owner 册；跨专业影响只以稳定引用和影响边界表达，不改写他册正文。
