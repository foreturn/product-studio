# 安全工程 · 运行环境加固

### 运行环境与安全配置

- 每个工作负载应使用独立最小权限身份，角色委派和权限传递不能形成低权限到高权限的隐式路径。
- 运行进程应以最小系统权限、最小可写范围和最小宿主访问运行，隔离边界不能仅依赖逻辑命名空间。
- 制品必须来源明确、不可变且只含必要组件，已验证内容与实际运行内容必须保持同一身份。
- 网络访问默认受限，东西向与外部访问都应按业务需要开放，防止局部失陷扩展为横向移动。
- 生产环境必须关闭调试、示例入口、默认凭据和过度错误披露，管理面应有独立身份、访问边界与审计。
- 传输保护必须覆盖不可信边界并验证通信对端，环境内部位置不能替代身份认证。
- 安全基线必须由可验证配置与运行实态共同证明，框架或平台默认值不能视为永久安全结论。
