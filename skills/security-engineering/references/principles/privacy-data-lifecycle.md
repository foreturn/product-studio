# 安全工程 · 隐私与数据生命周期

### 隐私、数据最小化与删除传播

- 每个个人或敏感字段必须有明确处理目的、接收者、地域、保留依据和副本范围，无法证明必要性的字段不应采集。
- 身份识别不是处理目的所必需时，应降低可识别性；稳定散列和可逆令牌仍可能关联主体，不能直接视为匿名。
- 同意或其他合法处理依据必须与具体用途关联，目的变化不能默认沿用原有许可。
- 访问、导出、更正和删除必须重新校验主体与数据范围，不能因请求来自已登录会话便扩大处理权限。
- 删除应传播到主存储、缓存、搜索、分析、对象和第三方副本，并明确备份、保留义务与恢复后的处理边界。
- 非生产环境、支持活动、日志和分析同样受数据最小化约束，复制生产数据不能成为测试便利的默认方案。
