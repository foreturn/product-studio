# 安全工程 · 密码学与密钥管理

### 密码学、密钥与秘密生命周期

- 密码学原语必须按保密、完整性、真实性、密码存储或随机令牌等不同目标选择，编码和普通散列不能替代安全原语。
- 使用成熟、受审查的算法与库并采用当前安全参数，禁止自创协议、复用不相容用途的密钥或关闭必要完整性保护。
- 加密数据必须能够识别算法、密钥版本和绑定上下文，并保证同一密钥下所需随机量或唯一量不被危险复用。
- 数据密钥与高权限主密钥应分层隔离，取得数据存储或应用读取权限不应自动取得全部解密能力。
- 优先使用与工作负载绑定的短期凭据；静态秘密必须按服务、环境和用途分离，并远离源码、制品、普通配置与日志。
- 密钥和秘密必须具备创建、分发、轮换、撤销、销毁和泄露响应能力，无法定位消费者便无法证明轮换完成。
- 轮换必须兼容仍需读取的历史数据和过渡期消费者，旧值最终应被拒绝，不能只生成新值而长期保留旧信任。
