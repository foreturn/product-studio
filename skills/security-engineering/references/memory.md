# 安全工程项目记忆

## 核心记忆

### 资产、数据流、信任域与威胁前提

- 记住产品需要保护的账户、权限、业务对象、个人与敏感数据、制品、秘密和运行能力，其价值、所有者、允许用途与受损后果，以及外部参与方和攻击者实际具备的能力。
- 记住数据和控制从客户端、服务、管理面、后台任务、消息、存储到第三方的真实流向与信任跨越，每道边界的入口、可信假设、预防、限制、检测和恢复责任落在哪个不可绕过的组件。
- 记住当前接受、缓解和明确不覆盖的威胁场景、攻击前提、爆炸半径与剩余风险，以及入口、身份、数据、依赖、部署或第三方边界发生何种变化时必须重做相关威胁判断。

### 身份认证、联合身份、多因素与账户恢复

- 记住人类、设备、服务和其他工作负载身份的权威来源、关联与生命周期，注册、登录、联合身份和本地凭据分别验证的签发方、接收方、时间、请求关联和账户不变量。
- 记住各类普通与高风险动作要求的认证强度、近期认证和多因素组合，挑战、拒绝、锁定、限流与账户枚举防护的稳定语义，以及机器身份同人类身份不可复用的边界。
- 记住密码找回、恢复码、可信渠道和人工恢复的凭据、次数、时限、账户绑定与通知规则，恢复成功后旧会话、认证因子与风险状态如何收敛，哪些弱恢复路径不得绕过强认证。

### 会话、令牌与失效传播

- 记住各客户端和服务使用的会话或令牌类型、签发者、接收方、作用域、绑定上下文、有效期与保护能力，以及哪些长期高价值秘密不得交给无法可靠保密的客户端。
- 记住会话签发、续期、轮换、并发刷新、重用检测、撤销和过期的完整状态，身份提升、密码或因子变化、账户停用和风险事件触发何种失效范围与传播时限。
- 记住退出、刷新结果未知、多个设备或服务并发和失效服务不可用时的确定行为，令牌完整性、来源、时间和上下文在何处校验，以及仅解析声明、客户端删除或本地超时不能证明的服务端状态。

### 授权、对象访问、租户与特权隔离

- 记住角色、能力、属性和关系授权的权威来源与服务端决策点，每项决策实际包含的主体、动作、具体对象、租户与环境上下文，以及默认拒绝和对象级校验的不可绕过位置。
- 记住列表、搜索、计数、聚合、导出、批量、消息与后台任务如何继承详情访问的对象和租户约束，缓存、派生结果和异步载荷携带何种可信作用域，权限变化后旧决策怎样失效。
- 记住委托、服务身份、管理员和紧急特权的最小能力、期限、再认证、审批与审计边界，以及拒绝访问时必须保持的错误与数据不可见语义、客户端隐藏绝不能替代的控制。

### 解析、内容、外部通信与滥用防护

- 记住外来文本、结构体、富内容、文件、路径、URL、模板和跨来源消息进入哪些解析或解释上下文，采用何种规范化、结构化构造、安全子集、协议与目标限制，以及时间、内存、深度和大小边界。
- 记住浏览器、移动端、回调、Webhook、跨服务请求和第三方嵌入的发送方、接收方、环境、完整性、时效、唯一性与重放校验，拒绝恶意输入时不得继续产生的持久化或外部副作用。
- 记住登录、读取、搜索、上传、导出、批量和高成本动作按主体、租户、资源、突发速率、长期配额、并发与执行时长实施的限制，保护机制的错误、响应和时延不得泄漏的账户或对象状态。

### 密码学、密钥与秘密生命周期

- 记住每项加密、签名、完整性、密码存储和随机令牌使用的目标、成熟算法与库、参数、算法标识、密钥版本和绑定上下文，以及禁止复用的密钥用途与唯一量。
- 记住数据密钥、主密钥、证书和静态或短期秘密的创建、存储、授权、注入、分发、轮换、撤销、销毁与泄露响应，哪些组件和环境可取得何种能力，以及密钥同数据访问的隔离关系。
- 记住历史数据和过渡消费者的解密或验签兼容窗口，旧信任最终拒绝的完成条件、全部消费者的定位入口，以及秘密不可用、轮换中断或消费者遗漏时必须采取的失败与恢复行为。

### 隐私、数据最小化与删除传播

- 记住每项个人或敏感字段的处理目的、合法依据、主体、接收者、地区、保留起点和副本范围，哪些字段必须采集、可降低可识别性或明确不得进入非生产、日志和分析环境。
- 记住访问、导出、更正和删除时重新校验的身份与数据范围，同意或其他依据的用途绑定，以及稳定散列、可逆令牌和字段组合仍可能关联或重新识别主体的边界。
- 记住删除、匿名化和保留如何传播到主存储、缓存、搜索、分析、对象、第三方与恢复后的备份副本，无法自动覆盖的外部或法定保留边界，以及传播完成和审计的权威证据。

### 软件供应链与运行时安全基线

- 记住依赖、基础制品、构建扩展和第三方组件的受控来源、不可变身份、传递范围、安装行为与维护责任，源码、依赖、构建环境、组件清单、签名和来源证明如何绑定到实际制品。
- 记住不受信变更、受信构建、签名与发布凭据之间的隔离，工作负载最小身份、系统权限、可写范围、宿主访问和网络出口，以及生产必须关闭的调试、示例、默认凭据和过度错误披露。
- 记住第三方、插件和外部服务进入信任域后可访问的数据与能力、失陷时的隔离范围和替代控制，漏洞适用性如何结合实际版本、配置、可达性与攻击前提判断，而非只沿用通用等级。

### 审计检测、漏洞验证与事件响应

- 记住认证、授权、特权、秘密访问、数据导出和策略变化在何处记录可信时间、主体、动作、对象、租户、来源、结果与关联，原始审计的防篡改、访问、保留和脱敏边界，以及检测链的已知盲区。
- 记住高风险攻击路径需要组合的信号、时间关系、基线、聚合抑制与升级条件，漏洞的最小安全复现、不可利用对照、同类变体和正常业务回归入口，以及扫描或单一样本不能证明的范围。
- 记住安全事件的分级、单一指挥、证据保全、遏制、凭据撤销、根除、可信恢复和必要沟通责任，受影响主体、数据、租户和地域中已证实与未知的范围，以及关闭前必须复测的安全不变量、检测回放和稳定观察期。
