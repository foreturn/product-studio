## 共同定位与写入契约

- **Owner**：`security-engineering` 唯一裁决安全事实的主题、四栏语义与 `ADD / UPDATE / DELETE / NO_CHANGE`；其他专业只可引用，不复制或改写正文。
- **Locator**：`<Git仓库根>/docs/product-studio/<product-id>/security-engineering.md`。
- **product-id**：由用户范围、仓库原生产品身份、运行入口、代码、配置、数据流与信任边界共同确认；必须唯一、稳定并可安全作为单级目录名，不得仅取目录名。多产品仓库逐产品隔离，归属不唯一时不得写入。
- **当前证据**：只有当前代码、配置、策略、依赖锁、扫描或测试及相称验证证实的现行控制语义可以入册。风险愿望、外部合规原文、一次性扫描结果和未执行控制不得写成当前事实。
- **写权限**：只有取得本轮事实册写权限时方可修改；只读分析只形成脱敏候选主题与证据，不得创建目录、空册或改动既有内容。
- **秘密边界**：事实册只能保存控制语义和脱敏定位，不得出现真实秘密、令牌、私钥、连接串、个人数据、生产样本或可直接利用的环境细节。
- **主题粒度**：一个主题承载一个共同检索、共同变化的安全语义，不按任务、漏洞编号、文件、端点或扫描项机械拆分。

## 统一实例格式

```markdown
# security-engineering 当前产品事实

## <稳定事实主题>

- **当前事实**：<当前执行的安全控制、适用条件与明确限制>
- **权威依据**：<一至三个脱敏的 `仓库相对路径#策略、配置、Symbol、测试或扫描精确位置`>
- **影响边界**：<主体、资源、租户、数据、入口、外部系统及明确不适用处；无则写“无”>
- **复核入口**：<可重复的测试、扫描、脱敏复现或配置检查、关键断言与重审触发>
```

四栏必须同时存在。主题或任一栏改变均按对应事实类型的变更规则处理；删除后不保留漏洞时间线、历史秘密指纹或失效控制占位。

## 事实类型：资产与数据分类

- **入册条件**：系统已对稳定资产、数据类别或关键处理活动执行明确分级，并由代码、Schema、配置或策略将等级映射为访问、存储、传输、日志或保留控制。
- **主题合并键**：以“资产或数据集合 + 分类级别 + 控制组合”合并；同一数据集合的敏感级别、处理目的和控制边界写入同一主题。
- **当前事实写法**：写明资产或数据集合、分类等级、识别依据、允许处理者、存储传输日志限制、降级或去标识条件及不适用范围。
- **权威依据**：引用数据模型或 Schema、分类配置、处理入口、脱敏规则、日志过滤和覆盖分类控制的测试；标签文档无执行落点不足以入册。
- **影响边界**：列出主体、租户、存储、日志与分析系统、外部接收者、地域及明确不包含的数据集合。
- **复核入口**：提供数据流检查、日志泄漏测试、分类配置校验、脱敏或导出验证；新增字段、处理目的、接收者、地域或分类政策变化时重审。
- **变更规则**：`ADD` 用于形成新的已执行分类控制；`UPDATE` 用于等级、处理限制、依据或影响范围改变；`DELETE` 用于资产、数据集合或控制彻底移除；四栏均未改变则 `NO_CHANGE`。
- **专属禁项**：不记录真实个人数据、生产样本、纯合规条文或未经系统执行的标签；数据库列类型本身不能单独证明数据分类。

## 事实类型：身份与会话

- **入册条件**：系统已执行稳定主体识别、认证、凭据校验、会话签发续期撤销、多因素或服务身份机制，并对后续入口构成共同约束。
- **主题合并键**：以“主体类型 + 认证方式 + 会话或凭据生命周期”合并；同一主体的签发、校验、续期和撤销写在一个主题。
- **当前事实写法**：写明主体、认证因子或凭据类型、签发者与校验者、有效期和续期、绑定与撤销、失败限制、跨边界传播及匿名例外。
- **权威依据**：引用认证中间件、令牌或会话配置、密钥标识而非秘密值、撤销存储、服务身份配置和正反向测试。
- **影响边界**：列出用户或服务主体、入口、客户端类型、租户、会话存储、身份提供方、信任区域及不适用认证路径。
- **复核入口**：提供无效、过期、撤销、重放、固定会话、凭据轮换或身份提供方异常测试；签发者、算法、有效期、客户端或传播路径变化时重审。
- **变更规则**：`ADD` 用于新增稳定身份或会话机制；`UPDATE` 用于认证方式、生命周期、传播、依据或主体范围改变；`DELETE` 用于机制及最后主体移除；无四栏变化则 `NO_CHANGE`。
- **专属禁项**：不记录令牌、Cookie 值、密码、私钥、真实主体标识或可用于绕过认证的环境细节；不把 UI 登录状态当作服务端身份事实。

## 事实类型：授权与租户隔离

- **入册条件**：系统已执行稳定主体、动作、资源或租户决策，包含默认拒绝、角色或属性规则、对象级校验、管理例外或跨租户隔离。
- **主题合并键**：以“主体类别 + 资源域 + 动作或租户不变量”合并；同一资源域的入口检查、对象过滤与管理例外写在同一主题。
- **当前事实写法**：写明受控主体、资源与动作、租户来源、决策点、默认行为、对象级条件、特权例外、拒绝语义及无法由该控制覆盖的路径。
- **权威依据**：引用策略或权限定义、服务端决策入口、租户过滤或数据库策略、网关控制和越权正反向测试；前端隐藏按钮不得作为授权依据。
- **影响边界**：列出角色或属性主体、资源集合、租户、后台任务、管理入口、外部调用者和明确公开资源。
- **复核入口**：提供未认证、低权限、水平越权、垂直越权、跨租户、后台任务与缓存隔离测试；资源、角色、租户来源或决策点变化时重审。
- **变更规则**：`ADD` 用于建立新的授权或租户不变量；`UPDATE` 用于主体、资源、动作、例外、依据或影响范围改变；`DELETE` 用于控制或对应资源域移除；四栏一致则 `NO_CHANGE`。
- **专属禁项**：不记录待批准权限矩阵、仅前端可见性规则或没有服务端强制的角色声明；数据主权拓扑不是授权事实。

## 事实类型：输入、API 与滥用防护

- **入册条件**：系统已对稳定入口执行输入解析与校验、输出编码、上传限制、请求签名、幂等、防重放、速率、配额或自动化滥用控制。
- **主题合并键**：以“入口族 + 威胁类别 + 控制组合”合并；同一入口族的校验、限额、防重放和失败响应写入同一主题。
- **当前事实写法**：写明入口与信任来源、允许格式和大小、规范化顺序、拒绝条件、速率或配额键、窗口和豁免、防重放或幂等语义及失败行为。
- **权威依据**：引用解析与校验 Schema、中间件、网关或 WAF 配置、上传处理、限流存储、签名校验和恶意输入或超限测试。
- **影响边界**：列出公开与内部入口、主体或 IP/租户键、上传存储、下游解析器、第三方回调、共享配额和明确豁免路径。
- **复核入口**：提供畸形、超长、编码绕过、注入、重放、并发超限、配额隔离和回调伪造测试；输入 Schema、代理拓扑、限额键或下游解析器变化时重审。
- **变更规则**：`ADD` 用于新增稳定入口控制；`UPDATE` 用于校验、限额、签名、防重放、证据或入口范围改变；`DELETE` 用于入口或控制移除；当前四栏一致则 `NO_CHANGE`。
- **专属禁项**：不记录可直接利用的攻击载荷、生产 WAF 例外、真实签名材料或一次性封禁名单；普通业务校验若无安全不变量不入本册。

## 事实类型：秘密与密码学

- **入册条件**：系统已执行稳定秘密来源、注入、访问、轮换和泄漏防护，或通过经批准算法实现传输、静态、字段级加密、签名、哈希或密钥派生。
- **主题合并键**：以“秘密或受保护数据类别 + 密码学用途 + 密钥生命周期”合并；同一用途的算法、密钥来源、轮换和失败行为写入同一主题。
- **当前事实写法**：只写秘密类别、来源类型、消费边界、密钥标识方式、算法与参数类别、轮换或版本策略、失败关闭行为和历史密文兼容条件，不写任何秘密值。
- **权威依据**：引用秘密装载接口、脱敏配置、密码学 API 调用、算法配置、密钥版本处理和测试向量；仅写“已加密”而无算法与用途证据不足以入册。
- **影响边界**：列出消费服务、数据类别、传输或存储路径、密钥管理系统、轮换参与者、旧密文和不受保护范围。
- **复核入口**：提供测试密钥下的加解密或签名验证、错误密钥、旧版本密文、轮换、日志脱敏和秘密缺失测试；算法、密钥来源、版本或数据用途变化时重审。
- **变更规则**：`ADD` 用于形成新的秘密或密码学控制；`UPDATE` 用于来源、算法、版本、轮换、依据或覆盖范围改变；`DELETE` 用于用途及控制彻底移除；四栏无变化则 `NO_CHANGE`。
- **专属禁项**：严禁秘密值、令牌、证书私钥、连接串、密码、密钥指纹清单和可定位生产密钥的环境细节；自创算法或未批准参数不得写成可靠控制。

## 事实类型：隐私与数据生命周期

- **入册条件**：系统已对个人或可识别数据执行稳定收集最小化、目的限制、同意或合法性标记、访问更正删除、导出、保留、去标识或接收者限制。
- **主题合并键**：以“数据主体或数据集合 + 处理目的 + 生命周期控制”合并；同一目的的收集、使用、保留、导出与删除写入同一主题。
- **当前事实写法**：写明数据集合、处理目的、必要字段、合法性或同意信号的系统落点、保留起算点、删除或匿名化语义、主体权利入口、接收者及例外。
- **权威依据**：引用收集与处理入口、同意或目的字段、保留删除作业、导出或更正实现、去标识规则和覆盖权利请求的测试；政策文本仅可辅助说明。
- **影响边界**：列出数据主体、租户、存储和副本、日志或分析系统、外部接收者、地域、备份例外及明确非个人数据。
- **复核入口**：提供最小化字段检查、同意撤回、访问导出、更正删除、保留边界、去标识和下游传播测试；字段、目的、接收者、地域或保留规则变化时重审。
- **变更规则**：`ADD` 用于新增已执行隐私生命周期控制；`UPDATE` 用于目的、字段、期限、权利语义、依据或影响范围改变；`DELETE` 用于处理活动及其数据彻底移除；四栏一致则 `NO_CHANGE`。
- **专属禁项**：不记录真实个人数据、主体请求内容、法律意见或纯政策承诺；数据库清理作业的物理细节不替代隐私目的与生命周期事实。

## 事实类型：供应链与安全配置

- **入册条件**：构建和运行链已执行稳定依赖锁定、来源校验、制品签名或证明、漏洞阻断、最小镜像、配置基线、危险默认关闭或环境分离控制。
- **主题合并键**：以“制品或配置域 + 信任来源 + 强制控制”合并；同一构建或运行域的来源、锁定、校验和阻断条件写入同一主题。
- **当前事实写法**：写明受控制品或配置、允许来源、版本或摘要锁定方式、签名或证明要求、扫描与阻断阈值、基线偏差处理、环境覆盖和失效行为。
- **权威依据**：引用锁文件、构建清单、仓库或镜像源配置、签名验证、SBOM、扫描策略、基线配置和篡改或违规依赖测试。
- **影响边界**：列出构建任务、包管理器、制品仓库、运行镜像、部署环境、第三方组件、配置消费者及豁免范围。
- **复核入口**：提供锁定重现、来源拒绝、签名或证明校验、已知漏洞阻断、基线漂移和危险配置测试；源、构建器、阈值、基线或豁免变化时重审。
- **变更规则**：`ADD` 用于形成新的供应链或配置基线；`UPDATE` 用于来源、锁定、阈值、基线、依据或覆盖范围改变；`DELETE` 用于制品域或控制移除；当前四栏一致则 `NO_CHANGE`。
- **专属禁项**：不记录未经处置的一次性扫描清单、仓库凭据、内部镜像令牌、临时构建故障或外部公告全文；版本升级过程不是当前控制事实。

## 事实类型：监测、漏洞与处置

- **入册条件**：系统已执行稳定安全事件生成、审计字段、检测规则、告警路由、漏洞修复不变量、遏制或复核机制，并能以脱敏方式重复验证。
- **主题合并键**：以“威胁或漏洞类别 + 检测或处置控制 + 受保护边界”合并；同类事件的信号、告警、遏制和验证写入同一主题，不按单个工单拆分。
- **当前事实写法**：写明检测或审计事件、必要脱敏字段、触发条件、告警或处置动作、去重与抑制、修复后强制不变量、保留边界和已知盲区。
- **权威依据**：引用事件定义、审计埋点、检测规则、告警配置、稳定修复代码、回归测试及脱敏扫描结果；单次告警或关闭工单不能单独证明长期机制。
- **影响边界**：列出受监测入口、主体和资源、日志或 SIEM 管道、值守接收者、自动处置对象、租户或地域及监测盲区。
- **复核入口**：提供测试事件注入、审计完整性、脱敏、告警路由、去重、稳定漏洞回归和扫描复现；事件 Schema、日志管道、检测阈值或修复不变量变化时重审。
- **变更规则**：`ADD` 用于新增稳定检测、审计或漏洞处置机制；`UPDATE` 用于信号、阈值、动作、修复不变量、依据或覆盖范围改变；`DELETE` 用于机制及对应威胁面移除；四栏无变化则 `NO_CHANGE`。
- **专属禁项**：不记录漏洞利用步骤、事故时间线、工单状态、责任人、未修复细节、真实告警样本或一次性扫描结果；历史由专门审计与漏洞系统承担。
