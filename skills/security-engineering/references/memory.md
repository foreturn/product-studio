# security-engineering 当前产品事实规则

## 所有权与稳定位置

- `security-engineering` 是当前产品安全终态语义事实的唯一 Owner；其他专业只能引用，不复制或改写本册事实。
- 本册拥有身份、授权、租户、来源准入、完整性与最小权限政策及不可绕过的安全不变量；后端只记调用契约怎样消费可信上下文，平台只记工作负载身份和制品通道机制，客户端只记系统权限与隐私能力适配，发布只记制品身份绑定与晋级，均引用本册而不复制政策正文。
- 稳定位置为 `docs/product-studio/<product-id>/security-engineering.md`；`product-id` 必须由产品身份、运行入口、数据流与信任边界共同确认，且可安全作为单级目录名。
- 多产品或共享安全平台仓库按真实产品归属分册；归属、信任边界或 Owner 不唯一时，不得读取候选册作为依据，也不得创建或修改事实册。
- 本册只索引当前成立的控制、不变量与经授权例外，不保存策略全文、攻击材料或外部状态正文。涉及长期兼容时，只记当前支持不变量、现存消费者与退出触发，不记阶段、目标态或推进进度。
- 只在本轮拥有事实文件写权限时落盘；安全审查、漏洞复现或生产观察本身不授予事实册写权限。

## 事实类型索引

1. 资产、数据与威胁边界
2. 认证与会话
3. 授权与租户隔离
4. 输入、API 与滥用防护
5. 秘密、密码学与隐私
6. 供应链与运行控制
7. 检测、响应、漏洞与例外

## 通用入册门禁

- **终态成立**：候选语义已由当前控制与风险相称的正反向验证共同证明，不是政策愿望、推断、临时缓解或进行中工作。
- **稳定**：候选语义预计跨越本次任务持续成立；单次扫描、登录事件、告警、事故状态、运行快照和阶段进度不得入册。
- **非显然**：候选语义不能从命名、目录、框架默认、扫描标签或单个声明轻易重新得出，否则无需占用事实册。
- **决策相关**：候选语义会实质改变后续威胁判断、安全实现、审查、检测、响应或风险接受决定。
- **重查昂贵**：若不索引，未来需要跨代码、配置、数据流、信任边界、策略和可重复验证才能重新确认。
- **唯一 Owner**：Git 根、当前产品、`product-id`、主题合并键和 `security-engineering` 所有权均已唯一确认，且未在他册重复。
- **可复核**：当前仓库存在稳定权威定位，并有可重复入口验证所写控制、攻击前提、失败结果与适用边界。
- **安全**：候选内容已最小化并脱敏，不含秘密、个人或生产数据、攻击载荷、可利用细节、完整策略或原始证据。

任一门禁不成立即不得写入；证据、归属、授权或安全表达不足时只在本轮报告说明，不产生事实动作。证据冲突时先复核当前控制，不并存互斥事实。

## 主题表达规则

- 主题以稳定安全语义命名，不含路径、日期、任务号、漏洞号或动作前缀；同一合并键只保留一个当前主题。
- 每个主题必须表达当前事实、权威依据、影响范围与复核方式，并写清控制或例外、攻击前提、消费者、明确限制、证据盲区和重审触发。
- 不规定固定 Markdown H2、固定四栏、固定字段标签或统一字段顺序；可依事实类型与可读性使用段落、列表或表格。
- 表达应便于沿脱敏权威入口复核和原位合并，不按漏洞、策略文件、扫描项或测试用例机械拆题。
- 不收录漏洞利用详情、修改摘要、调查过程、运行快照、事故状态、扫描清单、时间线、责任人或待办。

## 动作语义

- `ADD`：主题合并键尚不存在，候选终态语义通过全部入册门禁且必备语义完整；新增一个当前主题。
- `UPDATE`：同一主题的当前事实、权威依据、影响范围或复核方式实质变化，且新语义通过全部门禁；原位保留唯一当前表述。
- `DELETE`：主题所述控制、威胁面、有效例外或最后受保护对象已从当前产品消失；删除完整主题，不保留历史漏洞占位。
- `NO_CHANGE`：沿权威依据完整复核后必备语义均无实质变化；不得因改写表达、调整顺序或更换呈现方式触碰事实文件。

## 事实类型

### 资产、数据与威胁边界

- **入册条件**：当前产品对稳定资产、数据集合、主体或信任跨越实施了明确控制语义，未来安全判断必须据此识别攻击前提与失败影响。
- **主题合并键**：以“资产或数据集合 + 信任或威胁边界 + 控制不变量”合并；共同变化的流向、主体与边界控制归入同题。
- **当前事实写法**：写明受保护对象、可信与不可信边界、关键流向、攻击者能力前提、已执行控制、失败结果、消费者与明确盲区。
- **权威依据**：定位数据模型与处理入口、部署或信任配置、控制落点和正反向测试，不复制资产清单、图示或政策正文。
- **影响边界**：列出主体、租户、入口、存储与日志类别、外部接收者、环境地域及不包含的数据集合。
- **复核入口**：验证代表性信任跨越、数据流、未授权访问与控制失败，并说明静态图或测试环境不能证明的边界。
- **变更规则**：资产语义、数据流、攻击前提、控制、消费者、边界或证据改变时 `UPDATE`；仅命名变化而安全语义不变时 `NO_CHANGE`。
- **排除项**：不记录资产清单、真实数据样本、价值金额、通用威胁百科、纯合规文本、未实施控制、事故状态和可利用环境细节。

### 认证与会话

- **入册条件**：当前主体依赖稳定身份建立、凭据校验或会话生命周期语义，多个入口必须据此接受、续接或撤销身份。
- **主题合并键**：以“主体类型 + 认证与会话不变量 + 消费边界”合并；共同签发、校验、绑定与撤销的身份语义归入同题。
- **当前事实写法**：写明主体如何被可信识别、凭据与会话适用边界、绑定和防重放语义、续接与撤销结果、失败关闭行为和匿名例外。
- **权威依据**：定位认证或会话实现、身份信任与撤销配置及正反向测试，不复制令牌、Cookie、密钥标识或协议参数。
- **影响边界**：列出用户与服务主体、入口、客户端、租户、会话存储、身份来源、环境和明确公开路径。
- **复核入口**：验证无效身份、错误作用域、过期与撤销、重放、会话固定、身份源故障和跨客户端结果，并说明外部身份源盲区。
- **变更规则**：身份建立、校验、绑定、生命周期、消费者、失败结果或证据改变时 `UPDATE`；内部机制等价替换时 `NO_CHANGE`。
- **排除项**：不记录令牌、Cookie 值、密码、私钥、真实主体、登录事件、会话快照、具体时长或可绕过认证的环境细节。

### 授权与租户隔离

- **入册条件**：当前系统将可信主体、动作、资源或租户绑定到稳定服务端强制语义，多个入口或后台消费者必须遵守同一拒绝与隔离结果。
- **主题合并键**：以“主体类别 + 资源域 + 授权或租户不变量”合并；共同约束对象、列表、缓存与异步路径的控制归入同题。
- **当前事实写法**：写明可信主体和租户来源、资源与动作绑定、服务端决策边界、默认拒绝、对象与集合隔离、特权限制、消费者和公开例外。
- **权威依据**：定位权限策略与服务端决策、租户过滤或数据库政策、后台上下文和越权正反向测试，不复制业务资格正文。
- **影响边界**：列出主体类别、资源集合、租户、列表与导出、缓存、后台任务、管理入口、外部调用者和公开范围。
- **复核入口**：验证未认证、低权限、水平与垂直越权、跨租户、集合泄露、缓存混淆及后台路径，并注明跨服务证据边界。
- **变更规则**：可信来源、资源动作绑定、决策点、租户不变量、消费者、例外或证据改变时 `UPDATE`；控制或资源域消失时 `DELETE`。
- **排除项**：不记录完整权限矩阵、产品资格正文、仅 UI 可见性、无服务端强制的角色声明、真实主体、一次拒绝日志和待批准政策。

### 输入、API 与滥用防护

- **入册条件**：当前入口族稳定执行解析、规范化、输出安全、上传隔离、防重放或滥用控制语义，且绕过会改变系统安全结果。
- **主题合并键**：以“入口族 + 威胁类别 + 防护不变量”合并；共同解析、限制、验证和拒绝的入口归入同题。
- **当前事实写法**：写明入口信任来源、允许输入语义、规范化与校验顺序、身份或租户计量边界、防重放、失败结果、消费者和明确豁免。
- **权威依据**：定位解析 Schema、中间件、网关或上传处理、签名或幂等校验和无害正反测试，不复制规则参数或攻击载荷。
- **影响边界**：列出公开与内部入口、主体与租户、上传或回调边界、下游解析器、共享配额、自动化调用者和豁免路径。
- **复核入口**：验证畸形、混淆编码、注入、重放、并发滥用、隔离与伪造拒绝，并说明生产流量与外部网关不能证明的部分。
- **变更规则**：输入语义、防护边界、计量身份、失败结果、消费者、豁免或证据改变时 `UPDATE`；仅参数调优且终态语义不变时 `NO_CHANGE`。
- **排除项**：不记录具体阈值、网关规则清单、攻击载荷、生产例外、真实签名材料、封禁名单、一次攻击事件和未执行防护计划。

### 秘密、密码学与隐私

- **入册条件**：当前产品对秘密或敏感数据实施稳定来源、保护、使用、轮换、最小化、目的或生命周期语义，未来消费者必须维持该安全结果。
- **主题合并键**：以“秘密或敏感数据类别 + 保护与生命周期不变量 + 消费边界”合并；共同使用、轮换、保留和删除的语义归入同题。
- **当前事实写法**：只写数据或秘密类别、保护用途、消费边界、版本兼容不变量、失败关闭、隐私目的、权利或删除结果、消费者与退出触发。
- **权威依据**：定位秘密加载与脱敏接口、成熟密码学调用、数据处理与生命周期实现及测试，不复制算法参数、秘密定位、政策或样本。
- **影响边界**：列出消费服务、数据主体与类别、传输存储路径、密钥系统、历史消费者、接收者地域、备份例外与未保护范围。
- **复核入口**：以测试材料验证篡改、错误密钥、轮换撤销、日志脱敏、最小采集、权利与删除传播，并说明法律判断或生产密钥盲区。
- **变更规则**：保护用途、消费边界、兼容不变量、隐私目的、生命周期、消费者或退出触发改变时 `UPDATE`；义务消失时 `DELETE`。
- **排除项**：不记录任何秘密、令牌、私钥、密码、连接串、密钥指纹、算法或参数清单、真实密文与个人数据、期限数值和处理进度。

### 供应链与运行控制

- **入册条件**：当前构建、制品或运行边界实施稳定来源、完整性、信任隔离、安全默认或最小权限不变量，消费者据此接受制品或运行状态。
- **主题合并键**：以“制品或运行域 + 供应链或运行不变量 + 消费边界”合并；共同建立来源信任与运行防护的控制归入同题。
- **当前事实写法**：写明受控制品或运行域、允许来源与完整性语义、构建信任边界、安全默认、最小权限、失败关闭、消费者和有期限例外。
- **权威依据**：定位依赖与构建声明、来源或制品校验、运行安全策略和绕过正反测试，不复制依赖、漏洞、镜像或配置清单。
- **影响边界**：列出构建任务、依赖与制品域、运行信任域、部署环境、进程或容器、网络文件边界、消费者和例外范围。
- **复核入口**：验证非授权来源拒绝、完整性与来源证明、秘密泄露防护、安全默认、最小权限和环境差异，并说明外部制品盲区。
- **变更规则**：来源、完整性、信任边界、运行控制、消费者、例外或证据改变时 `UPDATE`；仅依赖版本变化且控制语义不变时 `NO_CHANGE`。
- **排除项**：不记录依赖或漏洞清单、制品内容、构建日志、真实凭据、运行参数、配置值、扫描快照、版本升级过程和未实施加固建议。

### 检测、响应、漏洞与例外

- **入册条件**：当前产品具有稳定检测与响应语义、已验证的漏洞修复不变量，或确有经授权且具退出触发的当前风险例外，未来处置仍需复用。
- **主题合并键**：以“威胁或根因类别 + 检测响应或修复不变量 + 受保护边界”合并；同根因信号、处置、修复与例外归入同题。
- **当前事实写法**：写明脱敏信号语义、触发后的确定动作与权限、证据保全边界、恢复和关闭条件、修复后不变量，或例外的补偿控制与退出触发。
- **权威依据**：定位事件定义、检测与响应配置、运行册、根因控制点、正反回归和脱敏例外记录，不复制扫描或事故材料。
- **影响边界**：列出受保护资产与入口、主体资源、信号通道、处置对象、身份或密钥边界、同根因路径、例外作用域与监测盲区。
- **复核入口**：以测试事件或受控演练验证检测、证据完整性、遏制、信任恢复、关闭与修复变体，并验证例外补偿控制和退出条件。
- **变更规则**：信号语义、处置权限、关闭条件、修复不变量、补偿控制、适用范围或退出触发改变时 `UPDATE`；仅发生事件或扫描而契约未变时 `NO_CHANGE`。
- **排除项**：不记录阈值、漏洞或工单清单、攻击步骤与载荷、事故状态或时间线、原始告警日志、人员、取证内容、扫描快照和调查进度。

## 全册安全与删除规则

- 严禁记录真实秘密、令牌、私钥、密码、连接串、个人或生产数据、攻击载荷、完整账户与网络细节及可直接利用的信息。
- 权威依据只写脱敏仓库相对路径与精确策略、配置、Symbol 或测试位置；不得复制算法参数、控制清单、扫描结果、事故材料或外部原始证据。
- 删除前确认终态控制、威胁面、有效例外、最后消费者、退出触发和所有当前依据均已消失；不因文件改名、一次测试失败或扫描暂时无结果而误删。
- 删除最后主题时移除事实文件；仅在产品目录无任何 Owner 事实文件时才移除产品目录，不留下空册或空目录。
- 同一事实不得复制到其他 Owner 册；跨专业影响只以稳定引用和影响边界表达，不改写他册正文。
