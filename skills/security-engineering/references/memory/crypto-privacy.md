# 安全工程项目记忆 · 密码学、秘密与隐私

- 记住每项加密、签名、完整性、密码存储和随机令牌使用的目标、成熟算法与库、参数、算法标识、密钥版本和绑定上下文，以及禁止复用的密钥用途与唯一量。
- 记住数据密钥、主密钥、证书和静态或短期秘密的创建、存储、授权、注入、分发、轮换、撤销、销毁与泄露响应，哪些组件和环境可取得何种能力，以及密钥同数据访问的隔离关系。
- 记住历史数据和过渡消费者的解密或验签兼容窗口，旧信任最终拒绝的完成条件、全部消费者的定位入口，以及秘密不可用、轮换中断或消费者遗漏时必须采取的失败与恢复行为。
- 记住每项个人或敏感字段的处理目的、合法依据、主体、接收者、地区、保留起点和副本范围，哪些字段必须采集、可降低可识别性或明确不得进入非生产、日志和分析环境。
- 记住访问、导出、更正和删除时重新校验的身份与数据范围，同意或其他依据的用途绑定，以及稳定散列、可逆令牌和字段组合仍可能关联或重新识别主体的边界。
- 记住删除、匿名化和保留如何传播到主存储、缓存、搜索、分析、对象、第三方与恢复后的备份副本，无法自动覆盖的外部或法定保留边界，以及传播完成和审计的权威证据。
