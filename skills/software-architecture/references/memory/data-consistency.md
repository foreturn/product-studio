# 软件架构项目记忆 · 数据与一致性

- 记住每类关键业务事实的唯一写入权威、稳定身份和责任边界，历史快照、派生视图、搜索索引、分析结果与缓存副本分别由谁生成、消费和重建。
- 记住数据跨边界传播的触发方式、顺序与允许陈旧度，缺口和冲突如何发现与裁决，写后可见、删除、匿名化、保留和重建怎样沿完整派生链收敛。
- 记住数据位置由哪些事务关系、访问模式、敏感等级、地域驻留、生命周期和恢复目标决定，以及哪些跨边界读取可以接受副本、哪些操作必须回到权威来源。
- 记住跨边界流程的持久状态、完成条件、重复与乱序语义、补偿和人工处置责任，以及读取陈旧、冲突发现、写后可见和结果不确定时对用户与调用方的保证。
