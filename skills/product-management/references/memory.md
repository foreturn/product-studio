# product-management 当前产品事实规则

## 所有权与稳定位置

`product-management` 只保存当前产品已经成立、会改变后续产品或体验判断的终态语义。目标角色、问题与价值、产品政策与状态、范围与兼容承诺、指标与护栏、验收与不回归、跨平台旅程与信息架构，以及产品层内容、交互、视觉和无障碍契约均归此 Owner；它只裁定用户应获得什么结果，不记录任一客户端框架、组件、导航、生命周期、系统权限或平台适配怎样兑现。技术实现保证归相应工程 Owner，并以本册主题作权威引用而不复制产品语义。

唯一事实册位置为 `docs/product-studio/<product-id>/product-management.md`。`<product-id>` 必须由仓库内稳定产品身份、真实入口与消费关系共同确认，不得从目录名、仓库名或包名机械推断。产品身份或唯一 Owner 不能确认时不读取、不创建也不修改候选事实册。

## 事实类型索引

1. 角色、问题与价值结果
2. 产品政策与状态语义
3. 范围、非目标与兼容承诺
4. 成功指标与质量护栏
5. 产品验收与不回归契约
6. 用户旅程与信息架构
7. 内容、交互、视觉与无障碍语义

## 通用入册门禁

候选事实必须同时通过以下全部门禁；任一项不满足便不写入：

- **当前终态**：语义已经在当前产品成立，并由当前实现、配置或生效契约与风险相称的验证共同支撑；目标状态、计划、进行中变更、失败结果和过程叙事不入册。
- **稳定**：语义预计跨越一次局部实现或单次任务仍成立，且变化时值得通知后续消费者；瞬时数值、临时开关、阶段进度和一次运行状态不入册。
- **非显然**：不能从单个命名良好的源码、Schema、路由、组件或配置项低成本直接推导；可机械生成的清单和源码摘要不入册。
- **决策相关**：遗忘该语义会实质改变后续产品取舍、体验判断、实现边界、验证范围或风险处置；只有背景价值而无决策消费者的内容不入册。
- **重查成本**：重新发现需要跨入口、跨契约或跨证据追踪，成本显著高于读取并复核一条语义索引；一条搜索即可重建的内容不入册。
- **唯一 Owner**：产品身份、专业归属和主题合并键均可唯一确认；相邻工程实现只作为依据或影响边界，不复制其专业事实正文。
- **权威复核**：写入前必须沿当前权威来源重新复核，既有事实册、历史提交、讨论或本轮 diff 只能帮助定位，不能自行证明事实仍成立。
- **安全**：内容处于授权写入范围，且不含秘密、密钥、凭据、令牌、个人数据、客户数据、原始研究材料或受限生产载荷。

本轮未修改但已重新核验的既有语义也可成为候选，仍须通过上述全部门禁。事实册记录当前产品事实，不记录“本轮做了什么”。

## 主题表达规则

每个主题使用稳定产品语义命名，不含日期、任务号、提交号、文件名、动作或事实类型前缀。一个主题聚合同一产品对象、语义边界与共同变化的事实；同义事实原位合并，不另建“新版”“迁移后”或按页面、字段、端点、测试编号拆散。

根据事实类型、语义复杂度与后续检索方式，主题可采用段落、列表、表格或其组合，不强制 Markdown 标题层级、固定分栏、字段顺序或标签名称。表达中仍须能够明确识别当前成立的事实及条件、权威依据、影响范围和复核方式；这些语义要素可以自然分布，但不得缺失、含混或由读者自行猜测。

权威依据应收敛为一至三个可定位的仓库相对路径、Symbol、配置键、契约位置或真实产品入口；外部依据须说明权威主体与适用边界。复核方式必须可重复，包含关键断言、环境限制、未覆盖边界与重审触发，不得只写“查看代码”或“测试通过”。

## 动作语义

- `ADD`：候选通过全部入册门禁，且事实册没有相同合并键或同义主题；新增一个语义要素完整的稳定主题。
- `UPDATE`：候选通过全部入册门禁，且同一主题的当前语义、权威依据、影响边界或复核入口发生实质变化；原位更新，不保留旧版叙事。
- `DELETE`：当前权威证据证明主题不再成立或最后一个真实消费者已经消失；删除该主题。
- `NO_CHANGE`：复核后当前事实、权威依据、影响范围与复核方式均未发生实质变化；事实册必须保持字节不变，不因表达载体或排版偏好触碰主题。

这些动作只描述事实册是否变化；回合如何收束由终态记忆协议负责。

## 事实类型

### 角色、问题与价值结果

- **入册条件**：稳定角色、真实触发、当前问题、期望结果及产品能力到直接用户或业务价值的关系已由当前产品共同证据证明，并持续约束范围、体验或验收判断。
- **主题合并键**：以“角色或资格族 + 触发场景 + 核心结果”合并；同一问题的直接价值与边界原位维护，不按访谈、页面、功能或渠道拆分。
- **当前事实写法**：写明谁在何种触发下遇到何种可观察阻碍、需要取得何种直接结果、产品当前承担何种价值，以及不能合理归因或明确不服务的结果。
- **权威依据**：优先引用已生效产品契约、真实产品入口、当前资格与结果行为、稳定聚合证据及明确产品裁决；研究结论只能与当前实现和契约共同支撑语义。
- **影响边界**：列出直接与间接角色、关键旅程、产品能力、价值消费者、范围和验收，并说明不适用角色、场景或远端业务结果。
- **复核入口**：沿真实入口复核角色资格、触发、阻碍与结果链，交叉检查契约和行为证据，写明环境、数据或样本限制以及角色、问题或结果变化这一重审触发。
- **变更规则**：角色资格、触发、问题、直接结果、价值边界、证据或适用范围实质变化时 `UPDATE`；内部实现变化但语义不变时 `NO_CHANGE`。
- **排除项**：不记录人物画像故事、单条意见、访谈原文、研究批次与样本快照、竞品功能、市场估算、愿望清单、功能产出或未经证实的因果关系。

### 产品政策与状态语义

- **入册条件**：业务对象的资格、前置、允许或拒绝结果、状态含义、例外或跨入口一致语义已由当前生效契约和实现共同证明，并会被多个判断或消费者复用。
- **主题合并键**：以“业务对象 + 政策或状态转换族 + 适用角色与范围”合并；跨入口同义规则只存一题，不按接口、页面、枚举值或错误码拆分。
- **当前事实写法**：写明业务对象、适用角色与前置、允许和拒绝的产品结果、结果状态、重复或异常动作语义、有效例外、适用范围及明确不支持行为。
- **权威依据**：优先引用生效产品契约、当前领域行为、统一状态语义、行为测试及可定位的正式业务或法规裁决；实现细节只作证据定位。
- **影响边界**：列出角色、入口、旅程、产品对象、验收和受该政策约束的消费者，并明确地区、渠道、人工流程或其他产品的边界。
- **复核入口**：复核适用的成功、拒绝、重复、撤回、过期和例外路径，核对当前契约与可观察结果，说明未覆盖环境和政策变化这一重审触发。
- **变更规则**：资格、前置、状态含义、允许或拒绝结果、例外、适用范围或权威来源改变时 `UPDATE`；错误码、存储或调用实现改变但产品语义等价时 `NO_CHANGE`。
- **排除项**：不记录完整状态枚举、授权矩阵、鉴权算法、数据库约束、接口字段、历史政策、候选解释、临时运营处置、目标规则或实施计划。

### 范围、非目标与兼容承诺

- **入册条件**：当前产品实际提供的完整能力边界、明确不提供的结果，或仍约束真实消费者的长期兼容承诺已由当前产品和消费证据证明，遗忘会导致范围扩张或兼容破坏。
- **主题合并键**：以“产品能力或结果闭环 + 适用消费者族 + 约束边界”合并；同一闭环的在内范围、非目标与兼容不变量共同维护。
- **当前事实写法**：写明当前成立的完整结果边界、必要组成、明确非目标、不得退化行为，以及兼容窗口中的受支持不变量、真实消费者和退出触发；不写阶段或迁移进度。
- **权威依据**：优先引用生效产品契约、当前可用入口与行为、真实消费者、兼容性测试和明确范围裁决；历史版本只辅助定位当前承诺来源。
- **影响边界**：列出角色、旅程、能力、入口、消费者族、兼容关系和验收范围，并明确不承诺的产品、环境或使用方式。
- **复核入口**：走查当前完整闭环与不得破坏路径，核对真实消费者和兼容断言，说明外部消费者可见性限制以及消费者或退出条件变化这一重审触发。
- **变更规则**：完整结果、在内边界、非目标、兼容不变量、真实消费者、退出触发或适用范围改变时 `UPDATE`；任务拆分、实现顺序或阶段进度变化为 `NO_CHANGE`。
- **排除项**：不记录路线图、待办、优先级队列、里程碑、迁移阶段、回填进度、版本或流量快照、未来目标蓝图、无当前消费者的预留范围或文件清单。

### 成功指标与质量护栏

- **入册条件**：稳定指标口径或质量护栏已成为当前产品判断契约，可从授权权威来源重复计算或验证，并持续影响取舍、验收或风险判断。
- **主题合并键**：以“产品结果 + 指标与护栏族 + 适用人群和观察范围”合并；主指标与直接副作用护栏可同题，不按查询、图表或事件名拆分。
- **当前事实写法**：写明指标对象、分子分母、去重、观察窗口、分群、排除、数据质量规则、适用判断阈值、直接护栏和归因限制；只写口径与决策语义，不写观测值。
- **权威依据**：优先引用生效指标契约、事件或数据语义、可重复查询定义、数据质量检查、明确产品阈值和当前消费该口径的判断入口。
- **影响边界**：列出角色、旅程、产品范围、决策与验收消费者，并说明数据延迟、地区、平台、异常样本和不可归因结果的边界。
- **复核入口**：在授权环境执行确定的查询或契约测试，核对窗口、分群、去重、缺失、异常和阈值解释，说明数据新鲜度及口径、来源或消费者变化这一重审触发。
- **变更规则**：口径、来源、窗口、分群、排除、质量规则、阈值、护栏、归因边界或消费决策改变时 `UPDATE`；查询优化但结果语义等价时 `NO_CHANGE`。
- **排除项**：不记录当前基线、实时数值、仪表盘截图、实验或采集进度、单次报告、原始事件样本、个人或客户数据、无分母总量或未经依据的精确目标。

### 产品验收与不回归契约

- **入册条件**：稳定用户或业务结果、禁止结果、恢复语义或兼容保护行为已成为当前实现与独立验收共同遵守的产品契约，且不能从单个测试名称完整重建。
- **主题合并键**：以“产品结果 + 角色或前置状态 + 适用范围”合并；同一结果的成功、拒绝、重复、恢复和不回归语义共同维护，不按测试用例拆分。
- **当前事实写法**：写明前置、用户或业务动作、可观察结果、禁止结果、必要恢复或重复语义、适用环境、受保护既有行为及明确未覆盖边界。
- **权威依据**：优先引用生效产品契约、当前可运行路径、稳定验收或行为测试、相关政策语义和明确不得破坏裁决。
- **影响边界**：列出角色、旅程、入口、实现消费者、兼容关系和受保护行为，并说明不适用的环境、渠道或产品。
- **复核入口**：执行可重复旅程或测试并断言前置、动作、期望与禁止结果，区分本地、模拟、浏览器、设备、真实集成和生产证据，注明契约变化这一重审触发。
- **变更规则**：前置、动作、结果、禁止结果、恢复、保护范围、环境或证据入口改变时 `UPDATE`；测试重命名、重排或实现重构而可观察语义不变时 `NO_CHANGE`。
- **排除项**：不记录测试清单、单次测试结果、覆盖率快照、验收过程、实现步骤、组件或字段列表、未通过的目标行为、主观形容词或纯技术断言。

### 用户旅程与信息架构

- **入册条件**：核心任务的稳定入口、阶段、决策、完成或恢复语义，或信息对象的分类、归属和查找关系已由当前产品和端到端证据证明，并跨多个局部实现约束体验。
- **主题合并键**：以“目标角色 + 核心任务或信息对象族 + 主入口”合并；跨页面、尺寸或平台属于同一任务语义时保持一题，不按路由拆分。
- **当前事实写法**：写明触发与主入口、关键阶段和决策、信息归属与查找方式、完成和退出、中断恢复、跨角色衔接及明确不支持路径。
- **权威依据**：优先引用生效产品契约、当前可运行界面、导航或对象语义、端到端测试和稳定任务走查；路由配置只作定位，不能替代产品语义。
- **影响边界**：列出角色、平台、入口、信息对象、前后置任务、可见性、实现消费者和其他产品边界。
- **复核入口**：从真实入口完成核心任务，检查导航上下文、分支、返回、退出和恢复，注明身份、数据、视口、浏览器或设备限制以及任务或分类变化这一重审触发。
- **变更规则**：入口、阶段、决策、完成、恢复、对象归属、标签、查找方式或适用角色改变时 `UPDATE`；内部路由或组件重构但用户路径语义不变时 `NO_CHANGE`。
- **排除项**：不记录全量页面树、路由表、菜单或组件清单、线框稿、组织架构、一次走查记录、截图流水、尚未实现旅程或导航改版计划。

### 内容、交互、视觉与无障碍语义

- **入册条件**：跨触点复用的术语或动作语义、可见状态与恢复、信息与风险层级、设计系统产品语义、响应式等价结果或无障碍不变量已由当前体验和验证稳定证明，并会改变后续体验决策。
- **主题合并键**：以“产品任务或对象 + 体验语义族 + 适用角色与触点”合并；同义内容、动作、状态和层级跨入口共同维护，不按文案键、组件、令牌、断点或页面拆分。
- **当前事实写法**：写明用户可见术语与动作结果、关键状态和恢复责任、主次信息与风险层级、组件或令牌的产品角色、跨尺寸和输入方式的等价任务保证、焦点与辅助技术语义及已知限制。
- **权威依据**：优先引用生效体验契约、当前可运行触点、设计系统语义、表单与状态行为、响应式和无障碍测试，以及经核验的浏览器、模拟器或真实设备证据。
- **影响边界**：列出角色、任务、入口、平台、主题、模式、本地化、品牌、输入方式、辅助技术和实现消费者，并明确允许平台适配与不适用环境。
- **复核入口**：在代表性触点复核长文本、关键状态、提交与恢复、层级、重排、缩放、键盘或触控、焦点、对比、非颜色线索与适用辅助技术，说明模拟和真实环境证据边界及语义变化这一重审触发。
- **变更规则**：术语、动作结果、状态与恢复、层级、设计系统产品角色、等价结果、焦点或辅助技术语义、已知限制或适用范围改变时 `UPDATE`；表现实现变化而语义和验证结果等价时 `NO_CHANGE`。
- **排除项**：不记录完整文案或翻译副本、CSS 声明、像素值、色值、令牌或组件全集、源码、断点表、截图、设计图层、单次可用性研究、自动扫描原始报告、审美偏好或未实现规范。

## 全册安全与删除规则

- 禁止写入秘密、令牌、密钥、密码、生产凭据、签名材料、个人数据、用户数据、客户数据、原始生产载荷、受试者身份、访谈原文或会话内容。
- 删除只表示当前事实已经消失；事实册不保留迁移史、旧值、废弃方案、任务总结、diff、验证流水或本轮说明，历史由版本控制保存。
- 最后一个主题删除后删除 `product-management.md`；产品目录没有其他专业事实册时才删除空目录，不创建空册、目录或占位主题。
- 写后核对产品身份、唯一 Owner、主题合并键、必需语义要素、权威依据可定位性、复核可重复性、跨册重复和敏感信息；发现同义事实归属其他 Owner 时保留一处权威正文，其余只引用影响边界。
