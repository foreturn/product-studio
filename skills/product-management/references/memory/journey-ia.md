# 产品管理项目记忆 · 用户旅程与信息架构

- 记住核心任务从真实触发点到确认结果的主入口、阶段、决策点、完成与退出方式，用户在每个阶段需要辨认的对象、状态、可执行动作和完成条件。
- 记住首次使用、重复使用、中断重入、跨角色交接和异常恢复时必须保留的身份、筛选、选择、编辑与业务进度，以及高成本、敏感或不可逆动作在决定前必须呈现的对象、范围和后果。
- 记住线上页面、移动端、通知、人工和线下渠道之间的标识、状态、结果与责任衔接，哪些步骤可简化或后台完成，哪些政策与风险确认不能因效率目标被绕过。
- 记住用户理解的核心信息对象、任务分类和稳定主归属，重复入口作为何种上下文引用存在，以及哪些部门、代码模块或数据表结构不得直接成为产品分类。
- 记住主导航、层级、当前位置、返回关系和高频入口的稳定语义，标签如何区分相邻概念并预示到达内容，以及不同角色和权限下哪些对象应可见、不可见或另有入口。
- 记住搜索、筛选、排序、分类和分页服务的真实查找任务，条件与结果范围如何解释，以及无权限、对象不存在、内容为空和筛选无匹配分别应呈现的含义与下一步。
