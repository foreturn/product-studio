# 产品管理项目记忆 · 内容语义与交互反馈

- 记住业务对象、角色、动作和状态的权威术语，标题、按钮、状态、页面说明、引导、空态与帮助内容如何从用户情境、任务、决策、结果和下一步表达，AI 或系统何时因影响可信度、预期、数据去向、责任或恢复而可作为叙述主体，以及跨触点不得混用的近义词、内部术语和无证据价值宣称。
- 记住主次动作依据频率、重要性、风险与可逆性形成的层级，加载、空、成功、拒绝、失败、离线、过期、部分完成和异步受理分别对应的反馈位置、持续时间与真实下一步。
- 记住校验、重复、重试、撤销、冲突和结果未知时必须保留的用户内容与恢复入口，错误信息应说明的影响与行动，以及不能依赖临时提示、悬停、动画或单一感官线索传达的关键语义。
