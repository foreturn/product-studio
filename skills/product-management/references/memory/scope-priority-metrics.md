# 产品管理项目记忆 · 范围、优先级与指标口径

- 记住当前产品从真实入口到可确认结果所必需的最小完整闭环，各能力之间的前置依赖、必要结果与完整性条件，以及用户步骤、业务状态与交接、异常恢复、规则重复、变更扩散和长期维护共同构成的整体简便性；孤立页面、接口或数据变化不能单独代表完成。
- 记住当前范围中的必要项、增强项、延后项和明确非目标，各项同用户价值、风险降低、政策义务或学习目标的关系，以及新增事实触发重新评估的条件。
- 记住优先级所采用的结果价值、失败风险、学习价值、依赖确定性、可逆性与验证成本，关键既有旅程、消费者承诺和数据完整性中不得为局部增量退化的边界，以及哪些前提证据、重复特例、隐藏状态或下游补救会使既有产品决定必须重审。
- 记住每项稳定指标所度量的对象、事件、计算口径、数据来源、观察窗口、分群和排除项，以及结果指标、领先信号与副作用护栏之间的关系。
- 记住用于采取何种产品行动的基线、阈值与决策规则，数据质量、样本、归因和可行动性限制，以及短期波动、低样本或局部改善不得外推的结论边界。
- 记住实验的假设、比较对象、暴露单位、观察边界、停止条件和护栏，无法可靠对照时采用的替代证据与应降低到何种强度的因果结论。
