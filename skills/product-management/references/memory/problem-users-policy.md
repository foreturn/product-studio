# 产品管理项目记忆 · 问题、角色与政策裁决

- 记住产品实际服务的发起者、使用者、审批者、数据主体和结果承受者，各自的资格、任务、决策权、触发情境与失败代价，以及这些角色何时是同一人、何时必须分开对待。
- 记住每类角色当前面对的现实阻碍、已有替代路径、问题发生范围与可观察代价，哪些事实支持问题成立，哪些因果关系仍是待证假设或只适用于特定分群。
- 记住产品能力预期带来的用户行为、用户结果和业务结果之间的因果链，长期价值、不可牺牲护栏，以及明确不服务或可能受损的角色、情境与诉求。
- 记住每个关键业务对象的角色、资格、前置条件、允许结果、拒绝结果、有效范围与人工例外，以及政策在界面、设备、接口和人工渠道之间必须保持的同义语义。
- 记住创建、处理中、完成、失败、取消、过期、重复、冲突和部分完成等真实状态的含义、合法来源、可执行下一步、终止条件与不可逆变化，不虚构项目不存在的状态。
- 记住产品政策同身份认证、资源授权和租户隔离的分界，权威规则缺失或冲突时必须保留的未裁决状态，以及何种角色、地区、法规或对象条件允许形成差异。
