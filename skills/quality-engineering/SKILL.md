# 质量工程

## 目标

在明确的验收对象、环境和证据边界内形成可复核的独立质量结论。此 Skill 约束质量工程工作如何启动、执行和收束；具体专业判断全部取自 `references/principles.md`。

## 执行协议

1. 确认本专业范围、目标产品与仓库、授权改动、受影响消费者、验证边界和未知项。
2. 阅读 [专业能力准则](references/principles.md) 的能力索引，并完整读取本次实际命中的能力条目。
3. 唯一确认 `product-id` 与事实 Owner 后，先按 [当前产品事实规则](references/memory.md) 的类型索引只读命中主题，再沿主题所指权威来源、相关实现、消费者与可重复证据复核；既有事实只作导航，不能替代当前证据。
4. 在授权范围内依命中准则完成最小充分实现或审查，不规定其他专业能力的选择、先后或数量。
5. 运行与风险相称的验证并检查最终差异，记录证据能证明与不能证明的范围。
6. 形成可交付终态后，按 [当前产品事实规则](references/memory.md) 检查本轮实际影响的主题：新增或更新候选执行全部入册门禁，既有主题沿当前权威与删除规则复核，再裁定事实动作和终态结果。

## 输出契约

- 验收对象、基线、环境与适用标准的明确身份。
- 风险和覆盖说明、创建或修改的质量资产、实际命令与退出码。
- 逐项证据、失败归因、残余风险和证据不能证明的边界。
- `PASS`、`FAIL`、`INCONCLUSIVE` 或 `NOT_APPLICABLE` 总体结论及其失效条件。
- 按终态记忆规则报告事实动作与结果；新增或更新候选未通过全部入册门禁时只留在本轮报告，不得据此改写既有主题；既有主题仍须沿当前权威独立复核。

## 完成条件

- 所有适用的高风险标准均有与当前对象匹配的直接证据或明确阻塞说明。
- 新增或修改的质量资产已按仓库原生入口运行，结果已实际读取。
- 总体结论不超出已验证的修订、制品、环境、身份、数据和时间边界。
- 未覆盖项、既有失败和本轮回归已清楚分离，复核入口可重复执行。
- 已沿权威入口完成受影响事实主题检查，源码摘要、任务过程、运行快照和单次结果均未写入事实册。

## 停止条件

- 验收标准或权威契约存在会改变预期结果的实质冲突。
- 必需环境、身份、数据、制品或工具不可得，且替代证据不足以支持结论。
- 继续操作将触及生产写入、真实用户数据、秘密或其他未获授权的外部状态。
- 验收对象在取证期间漂移且无法重新固定，既有证据不能继续绑定当前对象。

## 权限与边界规则

- 可在授权范围内读取代码、配置、日志和测试结果，并创建或修改测试、夹具与质量配置。
- 不把测试通过解释为生产健康、发布授权、产品政策成立或未检查环境可用。
- 不为其他专业补写其权威契约；输入矛盾时标明影响，不以实现现状降低标准。
- 不隐匿失败、改写既有测试以迎合实现，或用覆盖率、构建成功和快照数量代替行为证据。
- 不把被验证契约的正文、测试清单、报告摘要或当前运行结果复制为质量事实；只保存稳定且会改变后续验证判断的证据关系。

## 终态记忆

- 在最终答复前必须主动执行本节，不等待外部机制或用户再次提醒；仅在交付物形成可验证终态后同步事实。
- 对 `quality-engineering` 唯一确认 Git 根与 `product-id`；读取 `references/memory.md` 的所有权与稳定位置、事实类型索引、通用入册门禁、动作语义和全册安全与删除规则，再只展开本轮命中的事实类型与 `docs/product-studio/<product-id>/quality-engineering.md` 既有主题。
- 沿当前权威来源复核实际影响的主题；新增或更新候选通过全部门禁时才判定 `ADD` 或 `UPDATE`，当前权威证明既有主题或最后消费者消失时判定 `DELETE`，完整复核且无实质变化时判定 `NO_CHANGE`。未安全收束的主题不强判事实动作，并按下一项作 `DEFERRED` 收束；仅在拥有仓库写权限时才执行增改删，`NO_CHANGE` 必须保持事实册字节不变。
- 每个 Owner 只判定一个终态结果，优先级为 `BLOCKED` > `DEFERRED` > `SYNCED` > `NO_CHANGE`：交付物未形成可验证终态时为 `BLOCKED`；否则任一应检查主题因归属、证据、当前性或写权限不足而未安全收束时为 `DEFERRED`；全部安全收束且至少完成一项 `ADD`、`UPDATE` 或 `DELETE` 并复核写入时为 `SYNCED`；其余为 `NO_CHANGE`。
- 写后重读事实册并检查最终差异；最终答复以人类可读方式报告本 Owner 的终态结果、检查主题、事实动作、权威依据及必要的证据边界。
