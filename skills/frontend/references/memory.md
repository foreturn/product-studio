# frontend 当前项目事实记忆

本文件是 `frontend` 记忆的唯一规则与实例格式，目标实例为 `<项目根>/docs/product-studio/frontend.md`。只由 `frontend` 维护；其他技能可读取相关主题，不复制正文。

该事实册是 `frontend` 对整个项目的累计专业事实视图，不是单轮任务摘要。单轮只增量同步实际核验范围，整册不以该范围、最近差异或最后一次修改为边界，也不要求每轮扫描全库。

## 收录门槛

- 只记当前项目已经执行的界面任务、交互状态、恢复行为、布局、响应式、可访问性和共享设计约束；事实须有权威依据、可复核入口，且预计后续编码仍会使用。
- 事实是否入册只由当前是否成立、是否属于 `frontend`、是否值得后续复用决定，与本次是否修改相关代码无关；本次未触及但经当前权威来源核验的既有事实同样可以收录。
- 每个主题只描述一个共同检索、共同变化的稳定语义，不按任务、提交、文件、路由、组件、样式值、选择器、Symbol、截图或测试机械拆分。
- 重构、迁移、改名、组件替换和样式改造只是重新核对记忆的触发器，不得成为主题或事实正文；未完成阶段、临时双轨和执行进度不入册。
- 可从路由、组件注册、令牌或源码生成的完整清单不抄入记忆；只有最终仍成立的用户行为和多消费者约束才按当前状态记录。

## 实例格式

首次确有事实时创建同名事实册；没有事实时不得创建文件。主题使用简短、可读且稳定的业务语义，不含 Owner、类型前缀、路径、日期、任务号或变更动作。

```markdown
# frontend 当前项目事实

## <稳定事实主题>

- **当前事实**：<当前项目执行的一项界面任务、状态转换、恢复行为、布局或共享设计约束；用现在时写明必要条件、结果和边界>
- **权威依据**：<一至三个 `仓库相对路径#精确位置`，精确位置使用权威路由、组件、令牌、hook、store 或样式 Symbol>
- **影响边界**：<直接依赖的页面、组件、请求、状态拥有者、下游复用者、不得破坏的当前关系及明确不适用处；无则写“无”>
- **复核入口**：<可重复使用的测试、浏览器旅程或检查入口，以及关键状态、视口、断言、稳定未覆盖边界和适用的重审触发>
```

## 终态同步

1. 获准写入的实现、验收或明确记忆维护任务形成终态且取得相称验证后，以本次实际核验的当前代码、配置、契约和验证结果为本轮增量取材范围，对照现有主题重新判断当前事实；最终差异只用于定位变化与回归风险，不构成事实边界。
2. 同一语义原位改写；权威实现或证据搬移只改“权威依据”；事实或最后消费者消失时删除主题，不追加变更、重构或迁移历史。
3. 只有需要新增主题、改写“当前事实、权威依据、影响边界、复核入口”之一或删除事实时才写文件；完成当前范围核对后无增、改、删则报告 `memory: 0 facts changed`。
4. 只读分析或审查未获事实册写入授权时，只报告候选增改删及证据，不修改文件。
5. 最后一个主题删除后移除整册；写后检查主题、权威依据、影响边界和复核入口，再运行项目校验。

## 禁止内容

- 任务摘要、文件清单、进度、待办、责任人、候选方案、过程推理、前后对比、取代关系和历史版本。
- “从 A 迁移到 B”“本轮重构”“临时兼容”“改造阶段”等过程事实，以及单轮通过、临时失败、命令流水、制品、截图时间和 commit SHA。
- 未实现目标、外部资料、其他项目事实、密钥、令牌、用户数据、环境秘密，以及其他 Owner 已保存的同一事实正文。

历史由 Git 承担，长期设计缘由留在项目既有 ADR 或正式文档。静态校验只能证明当前快照的结构和依据自洽；语义新鲜度必须由 `frontend` 对照当前权威实现与本次实际核验范围同步。
