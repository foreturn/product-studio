# frontend 当前代码事实记忆

本文件是 `frontend` 记忆的唯一规则与首建骨架，目标实例为 `<项目根>/docs/product-studio/frontend.md`。只由 `frontend` 维护；其他技能可链接事实键，不复制正文。

## 收录门槛

- 事实已在当前代码中成立，有与风险相称的验证入口，且预计后续编码仍会使用。
- 事实具有唯一前端 Owner 和权威代码定位，并至少具备一项价值：跨消费者、无法从单文件立即看出、重查成本高或误判风险大。
- 一个键只概括一个共同检索、共同失效的稳定语义单元；不按任务、提交、文件、路由、组件、样式值、选择器、Symbol、截图或测试机械建卡。
- 可从路由、组件注册、令牌或源码生成的完整清单不抄入记忆，只保留稳定界面任务与多消费者约束。

## 事实键

键在当前项目内全局唯一；`<slug>` 只用小写字母、数字和短横线表达稳定业务语义，不写路径、日期、任务号或临时方案名。`<type>` 只取下列值：

- `frontend:surface:<slug>`：核心界面任务、入口、信息层级和结果。
- `frontend:component:<slug>`：多消费者共享的组件契约。
- `frontend:state:<slug>`：异步状态、服务端映射和恢复行为。
- `frontend:layout:<slug>`：稳定容器、网格、滚动和层级约束。
- `frontend:responsive:<slug>`：重排、溢出、触控和虚拟键盘约束。
- `frontend:a11y:<slug>`：核心旅程的语义、键盘、焦点和通知约束。
- `frontend:system:<slug>`：多消费者共享的令牌和设计系统规则。

## 实例骨架

首次确有事实时复制下列骨架并替换所有尖括号占位；没有事实时不得创建文件。`project_root: "."` 固定指事实册所在的当前项目根，不得改为绝对路径或父目录。

```markdown
---
memory: frontend
project_root: "."
updated_at: "<带时区 RFC3339 时间>"
---

# frontend 代码事实

## 当前代码事实

### frontend:<type>:<slug>

- **事实摘要**：<真实界面已经执行的一项任务、状态转换、恢复行为、布局或共享设计约束>
- **代码定位**：<一至三个 `仓库相对路径#精确位置`，精确位置使用权威路由、组件、令牌、hook、store 或样式 Symbol>
- **依赖与影响**：<直接依赖的页面、组件、请求、状态拥有者、下游复用者或相关事实键；无则写“无”>
- **验证入口**：<可重复使用的测试、浏览器旅程或检查入口，关键状态、视口、断言与稳定未覆盖边界>
- **失效条件**：<哪些组件、令牌、路由、接口、状态机、断点或浏览器支持变化后必须同步本卡>
```

## 终态同步

1. 编码任务完成，或部分完成中已有独立可用且验证成立的切片时，对照最终差异与现有相关卡列出 `+`、`~`、`-` 键。
2. 同一语义原位更新；仅搬代码时只改“代码定位”；事实或最后消费者消失时删除卡。
3. 只有五字段之一变化才写文件并更新 `updated_at`；没有总结事实变化时报告 `memory: 0 keys changed`，不制造时间戳差异。
4. 最后一张卡删除后移除整册，不留空文件；写后检查键、链接、定位和占位，再运行项目校验。

## 禁止内容

- 任务摘要、文件清单、进度、待办、责任人、候选方案、过程推理和 `superseded` 历史。
- 单轮通过、临时失败、命令流水、制品、截图时间、commit SHA、未实现目标、外部资料和其他项目事实。
- 密钥、令牌、用户数据、环境秘密，以及其他 Owner 已保存的同一事实正文。

历史由 Git 承担，长期设计缘由留在项目既有 ADR 或正式文档。静态校验只能证明当前快照的结构、定位和链接自洽；语义新鲜度必须由 `frontend` 对照最终差异同步。
