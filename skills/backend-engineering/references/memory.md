# 后端工程项目记忆

## 核心记忆

### 服务职责、领域不变量与状态语义

- 记住各服务与业务模块实际拥有和明确不拥有的领域能力、稳定概念、公共入口与副作用边界，以及接口、消息、任务和管理入口共同依赖的服务端不变量。
- 记住关键业务对象的创建条件、合法状态、具名转换、拒绝与终止规则、跨对象暂态和最终收敛条件，以及需要人工裁决而不能由代码静默代选的边界。
- 记住协议适配、用例协调、领域规则、持久化和外部机制的当前分层与依赖方向；存在依赖上下文的语义判断时，还要记住语义解释、结构化结果、确定性执行、歧义处理与保守降级分别由谁负责，哪些实现细节不得成为其他模块的隐式契约。

### API、身份、错误与兼容契约

- 记住真实调用方依赖的业务动作、请求与响应语义、缺省与空值、未知字段、边界值、过滤排序分页和完整或局部更新规则，以及契约版本和兼容期限。
- 记住身份、租户、权限、价格、审计主体和其他高价值上下文分别来自何处、在哪个可信边界校验与规范化，哪些客户端字段只能作为输入而不能成为权威事实。
- 记住成功、业务拒绝、认证失败、授权失败、资源冲突、限流、暂态不可用、结果未知与内部错误的稳定分类、对外结构和调用方下一步，以及不得泄漏的内部与供应商细节。

### 持久化模型、访问路径与数据边界

- 记住领域对象与持久化模型之间的显式映射、稳定身份、约束和保存语义，延迟加载、级联、默认映射与存储异常中哪些行为不能被当作领域规则。
- 记住关键读取、关联、筛选、排序、分页、批量改变和导出的所有者、规模前提与资源上限，以及哪些数据访问能力只供模块内部使用、不得作为任意查询接口外泄。
- 记住写入成功由何种权威存储结果、影响行数、约束或后续读取确认，冲突、约束失败、暂态不可用与未知提交如何转换为稳定业务或系统语义。

### 事务、提交与跨资源副作用

- 记住每项关键操作必须共同成立的业务不变量、实际事务边界、隔离资源与提交时点，以及哪些网络调用、用户等待和长时工作明确不在本地原子范围内。
- 记住本地状态、消息、文件、支付、通知和其他外部副作用的执行顺序与持久关联，进程在提交前后任意中断时哪些事实可能已生效、哪些必要动作必须能够重建。
- 记住多资源无法原子改变时暴露的部分完成状态、最终完成判据、补偿与人工修复责任，以及补偿只能新增何种可追踪业务事实、不能抹去哪些已对外发生的结果。

### 并发仲裁、幂等与资源保护

- 记住重复创建、检查后写入、丢失更新、顺序倒置和资源争用由哪个跨实例权威点仲裁，采用何种唯一约束、条件写、版本、锁或租约，以及冲突对调用方的确定语义。
- 记住幂等身份绑定的主体、租户、业务动作和请求语义，首次、处理中、成功、失败、超时与进程重启后的重复调用分别返回什么，以及同一标识携带不同意图时如何拒绝。
- 记住请求、集合、文件、批次、并发、队列和多层重试的总预算，取消、超时、陈旧执行者和未知结果如何停止无价值工作并释放资源，以及哪些副作用因不可安全重放而禁止自动重试。

### 消息、后台工作与业务收敛

- 记住每类事件、执行请求和普通通知的业务语义、生产者、消费者、稳定身份、关联标识、版本与最小载荷，以及“已入队”“已投递”“已处理”和“业务完成”的不同证明范围。
- 记住消息生产同权威状态的可恢复关系，消费端对重复、乱序、延迟、缺失和不可处理消息的保证，重试次数、死信或失败去向、重放入口和最终对账责任。
- 记住长时与定时工作的持久状态、唯一性、调度时间含义、并发上限、完成条件、暂停取消和断点恢复语义，以及积压、停滞、失败归宿和人工处置的观测入口。

### 缓存、读取一致性与身份隔离

- 记住每个缓存或派生读取视图的权威来源、所有者、缓存键所含参数、版本、账户、租户与权限作用域，以及填充、回源、失效、删除和重建关系。
- 记住产品对新鲜度、写后可见、单调读取和允许陈旧的实际承诺，写入后采用失效还是局部更新，权限变化、身份退出和敏感性变化如何传播到所有副本。
- 记住并发回填、热点失效、缓存故障和失效失败时的有界回源、降级与保护行为，哪些业务可以绕过或接受旧副本，哪些操作必须拒绝而不能返回无法判断的新鲜度。

### 外部集成、回调与调用韧性

- 记住每个外部系统承担的业务能力、双方对象与操作标识的映射、协议版本、限额和供应商模型转换边界，以及哪些外部响应只证明传输成功、不能证明内部业务完成。
- 记住调用链的端到端时限、连接和并发上限、允许重试的失败、退避、限流、熔断与降级规则，以及非幂等操作结果未知时的查询、对账和人工修复入口。
- 记住回调与外来通知的来源、环境、完整性、时效和重放校验，重复或乱序到达时的收敛语义，以及外部成功、回调到达、内部持久化和用户可见结果之间的最终判据。

### 性能、观测、审计与验证证据

- 记住关键业务路径的代表负载、数据规模、端到端延迟与容量预算、主要瓶颈和保护拐点，以及生产型环境、平均值、尾延迟、正确性和资源释放各自支撑的结论范围。
- 记住请求、消息、任务和外部交互使用的追踪关联、业务身份与幂等身份，错误、积压、健康、就绪和恢复信号的稳定含义，以及审计主体、动作、对象、结果与敏感信息处理规则。
- 记住纯规则、协议、真实数据库事务与锁、消息系统、外部替身和真实提供方分别能证明什么，哪些并发、重复、中断、恢复和容量结论必须在具备相应运行语义的环境中验证。
