# backend-engineering 当前产品事实规则

## 所有权与稳定位置

- `backend-engineering` 是当前产品服务端业务实现语义的唯一 Owner；其他专业只引用影响，不复制本册正文。
- 安全身份、授权与租户政策及不可绕过的强制不变量归 `security-engineering`；本册只记录服务端调用契约如何消费已经建立的可信上下文、返回何种业务或协议结果，不复制安全政策。
- 稳定位置为 `docs/product-studio/<product-id>/backend-engineering.md`；`product-id` 由产品身份、真实服务入口、模块归属与消费关系共同确认，不从目录或包名机械推导。
- 多产品仓库逐产品分册；产品、服务边界或 Owner 不能唯一确认时，不读取候选册作为依据，也不创建或修改事实册。
- 本册只索引当前终态的服务端语义、成立条件、保证与限制，不保存源码清单、实现摘要、过程、计划、迁移进度、运行快照或一次证据。
- 长期兼容只记当前支持不变量、现存消费者、兼容保证与退出触发，不记中间态、目标实现或推进状态。
- 只在本轮拥有事实文件写权限时落盘；只读任务仅报告候选动作与复核依据。

4. 消息与后台任务

## 通用入册门禁

- **当前终态**：候选语义已由当前执行实现与相称验证共同证明，且在交付终态真实成立，不是计划、推断或未完成工作。
- **稳定**：候选语义预计跨越本次任务持续成立；实现过程、迁移进度、运行快照与一次证据不得入册。
- **非显然**：候选语义不能从命名、目录、框架默认或单一声明直接、低成本推导。
- **决策相关**：候选语义会实质改变后续领域、接口、事务、消息、缓存、集成、资源或诊断判断。
- **重查昂贵**：未来重新发现该语义需要跨多处代码、配置、调用链、契约或可重复验证。
- **唯一 Owner**：Git 根、产品、`product-id`、主题合并键及 `backend-engineering` 所有权均已唯一确认，且他册无重复正文。
- **权威复核**：当前权威实现或配置有稳定定位，并可重复复核语义、条件、保证、限制与失败结果。
- **安全**：内容已最小化并脱敏，不含秘密、密钥、凭据、令牌、个人或生产数据及可利用的内部细节。

任一门禁不成立即不落册；证据、归属或授权不足时只在本轮报告。候选事实与既有主题冲突时，先沿当前权威来源复核，不并存互斥描述。

## 主题表达规则

- 主题以稳定服务端业务语义命名，不含路径、日期、任务号、动作或事实类型前缀；同一合并键只保留一个当前主题。
- 每个主题必须表达当前事实、权威依据、影响范围与复核方式，并写清成立条件、保证、消费者、明确限制、证据边界和重审触发。
- 不规定固定 Markdown H2、固定四栏、固定字段标签或统一字段顺序；可依事实类型与可读性使用段落、列表或表格。
- 表达应便于沿权威入口复核和原位合并，不按 Route、Symbol、消息、数据对象或测试用例机械拆题。
- 不收录源码清单、修改摘要、过程记录、迁移状态、运行观测原文、时间线或待办。

## 动作语义

- `ADD`：主题合并键尚不存在，候选终态语义通过全部入册门禁且必备语义完整；新增一个当前主题。
- `UPDATE`：同一主题的当前事实、权威依据、影响范围或复核方式实质变化，且新语义通过全部门禁；原位保留唯一当前表述。
- `DELETE`：主题所述服务端语义、保证或最后消费者已从当前产品消失；删除完整主题，不留历史占位。
- `NO_CHANGE`：沿权威依据完整复核后必备语义均无实质变化；不得因改写表达、调整顺序或更换呈现方式触碰事实文件。

## 事实类型

### 领域保证

- **入册条件**：当前服务端稳定强制某项领域状态、转换前置、拒绝或用例结果，多个入口或消费者必须共同遵守。
- **主题合并键**：以“领域对象或用例 + 不变量或行为族 + 消费边界”合并；同一保证跨入口只存一题。
- **当前事实写法**：写明可信前置、允许或拒绝动作、成功结果、副作用、重复或非法结果、消费者及明确不适用处。
- **权威依据**：定位领域对象、应用用例、状态机、命令处理、业务校验与不变量测试，不复制源码或字段定义。
- **影响边界**：列出 API、任务、消息消费者、批处理、管理入口、数据、下游读取者与不适用对象。
- **复核入口**：以领域或应用测试覆盖合法、非法、重复和边界状态，说明替身、数据库、跨进程与外部依赖限制。
- **变更规则**：前置、允许或拒绝、结果、副作用、消费者、适用条件或保证改变时 `UPDATE`；等价代码搬移时 `NO_CHANGE`。
- **排除项**：不记录领域类、枚举、字段或方法清单，不复制产品政策、数据库约束、候选状态、迁移过程或一次测试结果。

### API、错误与信任

- **入册条件**：当前调用面具有稳定且非显然的请求结果、可信身份来源、错误分类或兼容保证，真实消费者据此处理。
- **主题合并键**：以“协议调用面 + 业务操作族 + 信任或兼容边界”合并；共同契约不按字段或处理方法拆分。
- **当前事实写法**：引用安全身份与授权主题，写明入口协议如何接收和消费可信身份及租户上下文、关键前置、成功结果、业务拒绝与系统失败语义、兼容保证和不支持方式，不重述身份建立或授权政策。
- **权威依据**：定位接口契约、路由、请求响应类型、身份上下文、异常映射、序列化配置与契约测试。
- **影响边界**：列出客户端、内部服务、合作方、SDK、回调或批处理消费者，以及身份、租户、内容类型、环境与限制。
- **复核入口**：执行契约或协议级检查，断言成功、错误、序列化、可信身份、越权输入和现存消费者兼容，注明外部限制。
- **变更规则**：输入结果、信任来源、错误语义、兼容保证、消费者或条件改变时 `UPDATE`；内部实现替换时 `NO_CHANGE`。
- **排除项**：不抄录完整接口、DTO、错误码或端点清单，不保存令牌、请求样本、内部堆栈、产品文案或候选契约。

### 事务、副作用、并发与幂等

- **入册条件**：当前业务操作对提交、回滚、副作用、竞争、重复或冲突提供稳定结果，错误会造成状态分裂、重复影响或丢失更新。
- **主题合并键**：以“业务操作 + 原子或竞争边界 + 收敛保证”合并；共享提交命运与幂等语义的入口归入同题。
- **当前事实写法**：写明事务边界、内外副作用、提交回滚、竞争主体、幂等作用域、首次与重复结果、冲突重试及不保证资源。
- **权威依据**：定位应用服务、事务实现、仓储调用、可靠发布、补偿、条件写、去重或锁适配及并发测试。
- **影响边界**：列出领域状态、数据库写入、审计、文件、消息、通知、外部动作、并行调用者与跨资源限制。
- **复核入口**：以故障注入、重复调用和受控并发验证提交、回滚、副作用次数、冲突与最终结果，并注明真实环境限制。
- **变更规则**：原子边界、副作用、竞争键、幂等范围、冲突结果、重试、消费者或保证改变时 `UPDATE`；等价机制替换时 `NO_CHANGE`。
- **排除项**：不记录写入、锁或索引清单，不存事务教程、候选补偿、迁移步骤、执行过程、单进程假设或一次并发结果。

### 消息与后台任务

- **入册条件**：当前服务端稳定生产、消费或调度消息与任务，并对触发、交付、重复、顺序、重试或失败去向作出保证。
- **主题合并键**：以“消息或任务语义 + 生产消费责任 + 交付保证”合并；同一业务语义不按队列或处理函数拆分。
- **当前事实写法**：写明触发条件、载荷关键语义、生产或调度时机、消费者责任、交付顺序、去重重试、失败结果及不保证事项。
- **权威依据**：定位契约、发布器、消费者、可靠发布、调度与失败处理配置及消息或任务测试，不复制原始载荷。
- **影响边界**：列出生产与消费服务、后台任务、外部订阅者、领域对象、调度时间语义、重复副作用和对账责任。
- **复核入口**：在真实或明确标注的替代环境验证发布、消费、重复、顺序、失败重试与最终去向，注明时钟和多实例限制。
- **变更规则**：触发、关键语义、提交、交付、顺序、重试、消费者或失败结果改变时 `UPDATE`；技术命名变化时 `NO_CHANGE`。
- **排除项**：不记录队列、任务、调度或字段清单，不存积压快照、重放过程、运维流水、候选消息、秘密载荷或一次执行结果。

### 缓存与一致性

- **入册条件**：当前缓存参与业务读取或高价值路径，并具有稳定权威源、隔离、填充、失效、陈旧或故障语义。
- **主题合并键**：以“缓存业务视图 + 一致性范围 + 失效保证”合并；共享权威源与失效命运的键族归入同题。
- **当前事实写法**：写明缓存对象、权威源、作用域、读写模式、填充失效、允许陈旧、击穿保护、故障结果和不缓存内容。
- **权威依据**：定位缓存适配、键构造、读取与失效调用、事件监听、配置及一致性测试，不复制键或参数清单。
- **影响边界**：列出读写路径、租户或用户、任务、事件、下游消费者、数据新鲜度、环境与缓存不可用结果。
- **复核入口**：验证命中、未命中、并发填充、写后失效、过期、隔离与缓存故障，断言权威源和允许陈旧边界。
- **变更规则**：权威源、作用域、填充、失效、陈旧、保护、故障结果或消费者改变时 `UPDATE`；缓存产品替换时 `NO_CHANGE`。
- **排除项**：不记录缓存键、参数或容量清单，不存命中率快照、秘密、个人数据、热键状态、未来缓存设计或一次测量。

### 外部集成与资源保护

- **入册条件**：当前服务端与外部系统交互，并对协议结果、时间预算、重试、限流、熔断、回调、资源上限或降级作出稳定保证。
- **主题合并键**：以“外部系统或受保护资源 + 业务能力 + 失败与保护保证”合并；共同错误和资源命运的操作归入同题。
- **当前事实写法**：写明用途、标识语义、成功失败转换、时间预算、重试限流熔断、资源保护、回调校验、降级补偿和不支持能力。
- **权威依据**：定位集成适配、协议类型、客户端与资源配置、错误映射、回调校验、分页批量或背压实现及契约测试。
- **影响边界**：列出内部用例、外部供应方、租户、地区、网络、数据、调用者、资源边界、人工补偿与适用环境。
- **复核入口**：以契约、沙箱或受控替身验证成功、拒绝、超时、限流、重试、重复回调、资源耗尽与降级，说明外部证据限制。
- **变更规则**：协议语义、失败转换、时间预算、保护、回调、降级、消费者或适用条件改变时 `UPDATE`；客户端替换时 `NO_CHANGE`。
- **排除项**：不写密钥、证书、地址、外部文档、资源参数或性能清单，不存一次故障、负载快照、商务约定、候选供应方或容量推断。

### 观测与诊断

- **入册条件**：当前关键服务端行为具有稳定且非显然的关联、日志、指标、追踪、审计或健康语义，后续诊断需要复用。
- **主题合并键**：以“业务路径或故障族 + 诊断问题 + 信号关联范围”合并；共同语义与消费者的信号归入同题。
- **当前事实写法**：写明诊断问题、信号语义、关联标识、结果分类、敏感处理、采样或基数限制、健康含义、消费者和不覆盖事项。
- **权威依据**：定位埋点、上下文传播、健康检查、脱敏配置、信号测试与稳定查询入口，不复制日志或仪表盘内容。
- **影响边界**：列出服务、入口、任务、消息、下游依赖、诊断消费者、数据敏感度、环境与未覆盖故障。
- **复核入口**：触发代表性成功与失败路径，验证信号、关联、分类和脱敏，注明观测后端、采样、权限及生产限制。
- **变更规则**：诊断问题、信号、关联、敏感处理、健康含义、消费者或适用条件改变时 `UPDATE`；工具等价替换时 `NO_CHANGE`。
- **排除项**：不记录日志、仪表盘、告警或字段清单，不存请求载荷、个人数据、事故过程、运行快照、平台留存策略或一次查询结果。

## 全册安全与删除规则

- 不记录秘密、密钥、凭据、密码、令牌、证书、个人或生产数据、完整请求响应、原始消息、内部地址及可利用细节。
- 权威依据只写仓库相对路径和精确 Route、Symbol、配置、契约或测试位置；不复制源码、配置全文、运行观测或原始证据。
- 删除前沿当前权威确认服务端语义、保证、最后消费者与退出触发均已消失；不因改名、一次失败或暂时不可达而误删。
- 删除最后主题时移除事实文件；仅在产品目录无其他 Owner 事实册时移除空目录，不留空册或占位主题。
- 本册只裁定本 Owner 的 `ADD`、`UPDATE`、`DELETE`、`NO_CHANGE`；跨 Owner 回执、Hook 证据与终态结果结构不在本册定义。
