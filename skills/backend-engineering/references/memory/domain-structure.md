- 记住各服务与业务模块实际拥有和明确不拥有的领域能力、稳定概念、公共入口与副作用边界，关键行为从接口、消息、任务或管理入口经用例、状态、持久化和副作用到达何种可确认结果，以及哪些消费者共同复用同一服务端不变量和公共能力。
