# 后端工程项目记忆 · 集成韧性与观测

- 记住每类事件、执行请求和普通通知的业务语义、生产者、消费者、稳定身份、关联标识、版本与最小载荷，以及“已入队”“已投递”“已处理”和“业务完成”的不同证明范围。
- 记住消息生产同权威状态的可恢复关系，消费端对重复、乱序、延迟、缺失和不可处理消息的保证，重试次数、死信或失败去向、重放入口和最终对账责任。
- 记住长时与定时工作的持久状态、唯一性、调度时间含义、并发上限、完成条件、暂停取消和断点恢复语义，以及积压、停滞、失败归宿和人工处置的观测入口。
- 记住每个外部系统承担的业务能力、双方对象与操作标识的映射、协议版本、限额和供应商模型转换边界，以及哪些外部响应只证明传输成功、不能证明内部业务完成。
- 记住调用链的端到端时限、连接和并发上限、允许重试的失败、退避、限流、熔断与降级规则，以及非幂等操作结果未知时的查询、对账和人工修复入口。
- 记住回调与外来通知的来源、环境、完整性、时效和重放校验，重复或乱序到达时的收敛语义，以及外部成功、回调到达、内部持久化和用户可见结果之间的最终判据。
